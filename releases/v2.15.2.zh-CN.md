# Prompt Optimizer v2.15.2

## 概括

本补丁恢复流式输出自动换行和停止按钮，升级两项安全相关依赖，并收录 v2.15.1 之后的 Garden 浏览改进与 GPT Image 2.6 可选 GIF 输出支持。

## 亮点

- 长段落流式输出和原文视图按面板宽度换行，避免横向溢出。
- 普通工作区及全屏视图恢复单路文本流的停止操作。
- 就地搜索和浏览 Garden 灵感与竞技场测评题。
- 兼容的 GPT Image 2.6 接口可选 GIF 输出，默认仍使用 PNG。

## 产品更新

### Desktop

- 应用共用输出、Garden 浏览与图像输出改进。

### Web

- Garden 支持推荐与全部列表切换、目录搜索、追加加载和失败重试。
- 在同一工作区和语言下关闭后重开弹层，保留浏览位置及已加载内容。

### Extension

- 应用共用输出与 Garden 浏览改进。

### Core/Infra

- 在图片预览、存储和下载中保留 GIF 动画数据，兼容接口可使用可选帧数与帧间隔参数。
- 将 Vue I18n 固定为 11.4.14，并将间接依赖 Hono Node Server 统一约束为 2.1.3，覆盖 MCP SDK 的依赖路径。

## 修复

- 为流式输出及只读原文视图启用 CodeMirror 自动换行，覆盖长段落与长链接。修复 [#374](https://github.com/linshenkx/prompt-optimizer/issues/374)。
- 恢复嵌入、全屏和核心输出组件默认显示停止按钮的行为；显式禁用的通道，包括竞技场不可取消的通道，继续保持禁用。
- 将输出架构回归纳入日常浏览器门禁，持续检查优化历史、独立取消、终态持久化和并发渲染。
- 完善 Garden 图片卡片、原文展开、响应式弹层尺寸及翻页失败恢复。
- 将 Vue I18n 与 Hono Node Server 升级至修补版本，处理 [GHSA-83rm-6c8r-g728](https://github.com/advisories/GHSA-83rm-6c8r-g728)、[GHSA-8rc2-428q-7ww3](https://github.com/advisories/GHSA-8rc2-428q-7ww3) 和 [GHSA-rmxm-3fg6-px4f](https://github.com/advisories/GHSA-rmxm-3fg6-px4f)。

## 破坏性变更 / 升级说明

- 无破坏性变更，无需迁移备份格式。
- Garden 目录浏览需要服务端具备公开目录接口；GIF 生成需要所用接口支持对应格式及可选动画参数。
- 扩展 ZIP 版本为 `2.15.2`，继续供手动安装，本次不提交扩展商店。
- 正式发布流程从同一标签提交构建桌面、扩展和 Docker 产物，镜像检查通过后才提升稳定镜像别名。

## 开发者说明

- 浏览器覆盖 1440px 与 390px 输出布局、流式及完成后的原文、长链接、滚动到末行和复制内容一致性。
- 取消功能的单元测试覆盖两个包装组件中未传开关与显式禁用的行为；已有浏览器回归保留优化历史和取消断言。
- 发布流程在公开版本前执行仓库、核心、UI、Web 与浏览器门禁。CPU 降速和后台冻结模拟不代替所有原生桌面及低性能设备的验收。
