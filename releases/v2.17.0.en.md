# Prompt Optimizer v2.17.0

## Summary

Turn a brief and optional reference images into a video prompt in the new Video workspace. Edit the draft or ask for a revision. On web and desktop, you can then generate clips and compare the results side by side.

## Highlights

- Generate video with Seedance through Volcengine Ark or BytePlus ModelArk, or with MiniMax Hailuo. Depending on the model, you can start from text, supply a first frame and an optional last frame, or use several reference images.
- Compare two to four versions of a prompt or try the same prompt with different models. Adjust settings such as duration per column, then review which columns will run before you confirm generation.
- The **MCP preview** lets an AI assistant work with your desktop data or a browser profile you authorize. Ask it to optimize a saved prompt, test it with two of your configured text models and save the results to revisit in your MCP client.

## Product Updates

- After a refresh, the Video workspace resumes tracking active tasks and shows the latest completed result in each column. Download clips before their provider links expire. The browser extension supports writing and revising video prompts.
- Drag several images into the multi-image workspace and arrange the thumbnails in the order you want. Before optimization, you can see the estimated image upload size. Large requests use resized copies and keep your original references in the workspace.

## Fixes

- If you cancel a multi-image optimization or the request fails before new output arrives, the previous result stays available.
- When older revisions are trimmed from prompt history, each retained chain keeps its first version and the remaining revisions stay linked.

## Breaking Changes / Upgrade Notes

- On the first desktop launch after upgrading from v2.16.2 or earlier, the app automatically imports model settings, templates, history, favorites and workspace drafts into `prompt-optimizer-data.sqlite`. If you already ran a beta that migrated your data, the app opens that same database.
- The old `prompt-optimizer-data.json` holds a snapshot from the time of migration. Later edits are saved in SQLite. If you previously copied the JSON file for backups, open **Data Management** in the toolbar to export a current backup.
- Docker users can keep their existing `/mcp` URL and model configuration. The desktop and browser MCP preview is available separately on npm. If your client points to an executable bundled with an earlier desktop beta, change its launch command to `npx -y @prompt-optimizer/mcp-server@0.2.0-beta.4` using Node.js 24, 25 or 26. [MCP setup guide (in Chinese)](https://github.com/linshenkx/prompt-optimizer/blob/v2.17.0/docs/user/desktop-mcp.md)

## Developer Notes

Desktop storage imports the legacy records and marks the migration complete in one SQLite transaction. If the import is interrupted, the next launch can retry it.
