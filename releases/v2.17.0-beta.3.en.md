# Prompt Optimizer v2.17.0-beta.3

## Summary

Use the models and prompts you already keep in Prompt Optimizer from an MCP client. The client opens your existing desktop data by default. You can also connect a specific browser profile to optimize prompts, run tests and compare saved results.

## Highlights

- Read desktop models and favorites with the app closed. Run an optimization with one saved model and test its output with another.
- Connect two browsers to the same website and select each profile separately. A disconnected profile can be reauthorized to reopen its saved data.

## Product Updates

### Desktop

The Windows installer includes the MCP server. Choose **Help → Copy Codex MCP Configuration** to copy the executable and data paths for your installation. A connection can request read or write access.

### Web

Use a website running this beta's browser bridge, including a self-hosted beta deployment. Open the one-time authorization link in the intended browser profile and keep the tab open during use.

### Extension

Desktop backups containing saved comparisons or desktop runs must be restored in the desktop app. This also applies when moving data to the web app.

### Core/Infra

The npm beta adds the `prompt-optimizer-product-mcp` entry point alongside the legacy `prompt-optimizer-mcp` command. Both ship in the same self-contained package.

## Fixes

Closing an authorized tab invalidates its active connection. Explicit source IDs keep operations tied to the selected profile when several browsers use the same origin.

## Breaking Changes / Upgrade Notes

An upgrade from beta.2 uses the existing desktop SQLite database. Back up your desktop profile before upgrading. Desktop image and full-package operations require the desktop interface to be running.

## Developer Notes

The standalone MCP beta package is attached to this release. With Node 24.22.1, configure your MCP client to run the following command. On Windows use `npx.cmd`.

```sh
npx --yes --replace-registry-host=never --package=https://github.com/linshenkx/prompt-optimizer/releases/download/v2.17.0-beta.3/prompt-optimizer-mcp-server-0.2.0-beta.1.tgz prompt-optimizer-product-mcp
```

Set `--desktop-profile=<path>` or `--product-url=<URL>` to choose a different default source.
