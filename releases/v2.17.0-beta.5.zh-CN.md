# Prompt Optimizer v2.17.0-beta.5

## 概括

新增「视频」工作区。写下创作要求即可生成提示词，再编辑或按反馈迭代。在网页或桌面版中，可以并排观看不同提示词或模型生成的视频。

## 亮点

- 支持火山方舟、BytePlus ModelArk 的 Seedance，以及 MiniMax 海螺。按模型能力选择纯文本、首帧与可选尾帧，或多张参考图。
- 支持两到四栏对比。兼容的模型可共用时长等参数，也可以只改一栏，观察这个参数对成片的影响。提交生成前可以核对本次要运行的各栏。

## 产品更新

- 刷新后，工作区会继续跟踪进行中的任务，并保留各栏最近一次已结束的结果。成片可在栏内播放，也可在服务商链接过期前下载。浏览器扩展支持编写和迭代视频提示词，生成视频请使用网页或桌面版。
- 多图优化会显示待发送图片的预计大小，按需缩小本次请求中的图片副本。工作区保留原有参考图及排列顺序，方便继续编辑。

## 修复

- 多图优化在收到新输出前取消或出错时，会保留上一次的结果。
- 视频模型选择器显示实际模型 ID。调整下一次测试时，已提交的任务仍使用提交时的账号、模型和参数。

## 破坏性变更 / 升级说明

如果 MCP 客户端此前指向桌面应用内置的服务程序，请使用 Node.js 24、25 或 26，将 stdio 启动命令改为 `npx -y @prompt-optimizer/mcp-server@0.2.0-beta.4`。默认读取本机桌面资料。要使用网页数据，请在保存了目标资料的浏览器个人资料中授权连接。

此前的对照结果可在 MCP 客户端通过 `po_runs_list` 和 `po_runs_get` 找回。运行归档保存在原资料中。恢复旧 beta 的混合备份时，应用会导入产品数据，跳过其中的 MCP 归档。需要随产品备份迁移的优化提示词，请存入「历史记录」或「收藏夹」。
