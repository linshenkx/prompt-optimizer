# Prompt Optimizer v2.14.0

## Summary

This release adds local-service discovery and guided model setup, unifies workspace controls and model selection, and reorganizes data management and cloud backups. It also adds prompt-source hover previews and fixes configuration fields that could not be cleared reliably, category-parent clearing, and delayed hover previews covering the full-prompt dialog.

## Highlights

- **Discover local model services:** the text model manager identifies supported reachable services and offers a shortcut to the existing connection editor, with provider-specific setup guidance.
- **Clearer workspace controls:** consistent icons, compact source and model selectors, and responsive toolbars make configuration and output actions easier to find.
- **Inspect the prompt being tested:** hover to read a source preview on desktop, or open its full content directly. Source labels and model selection stay tied to the corresponding workspace.
- **Organized data management:** review device storage, export or restore a local file, and manage cloud backups through distinct sections with clearer connection and loading states.

## Product Updates

### Desktop

- Add controlled local-service probes through the desktop bridge and guided model connection setup.
- Preserve explicit field clears across desktop IPC when saving model configurations.
- Apply the shared workspace, source-preview and data-management improvements, including saved cloud-backup connection credentials and read-only connection/list operations.

### Web

- Discover supported reachable Ollama, Magpie, CLIProxyAPI, LiteLLM and llama.cpp services. Offer Chrome AI integration where the browser exposes the required capability.
- Prefill connection drafts and provide service-specific connection help. Model refresh, credentials, model selection and saving remain explicit user actions.
- Deduplicate already configured local addresses and keep model choices isolated between workspaces.
- Present device data, local files and cloud backups in a shared responsive data-management interface.

### Extension

- Use the updated workspace controls, model selectors and prompt-source previews in the extension interface.
- Keep multiple inline HTML previews independently interactive across preview/source switching and page lifecycle changes.
- Refine narrow-screen actions and the shared data-management and backup controls.

### Core/Infra

- Add local-service identification, model-catalog normalization and the Magpie adapter.
- Preserve explicit configuration clears through IPC serialization and model-update handling.
- Expand regression coverage for local discovery, connection drafts, workspace model isolation, backup workflows and source-preview interactions.

## Fixes

- Save a cleared category parent correctly so a category can be moved back to the root.
- Preserve explicitly cleared model configuration fields, including API keys, through the desktop service bridge.
- Ignore stale hover callbacks after a source menu closes, Escape cancels a pending preview, or the full-prompt dialog opens. The hover card no longer reopens over the dialog's controls.
- Restore clear prompt-source labels, keep workspace model selections independent, and fit compact action labels within available space.
- Persist cloud-backup credentials, retain existing lists after a refresh error, and ignore responses superseded by newer connection settings or authorization.
- Keep cloud connection checks and directory lookup read-only; creation and restoration remain separate actions.

## Breaking Changes / Upgrade Notes

- Export a backup of important application data before upgrading; the existing backup format and remote directories are retained.
- Local discovery does not read or create API keys, automatically import models, or make inference requests. Authenticated services still require the user's own client key. Browser access remains subject to CORS and local-network access rules.
- LM Studio and CC Switch do not have automatic discovery shortcuts in this release. Compatible services can still be configured manually through the model editor.
- The extension uses version `2.14.0` without a prerelease `version_name`. Install the ZIP manually; this release does not submit an update to browser extension stores.
- Docker images use the `2.14.0` tag and are promoted to `latest` after both registries pass verification. This release is available through the stable desktop update channel.

## Developer Notes

- Discovery offers connection drafts through the existing model editor and persistence flow, rather than automatically registering services or importing catalogs.
- Backup tests cover credential persistence, read-only connections, configuration drafts, import-code ownership and obsolete-response handling. Simulated authorization is not a real-account OAuth acceptance test.
- Source-preview regressions include seven workspace modes and rapid source selection followed by opening the full prompt. Packaged-extension tests retain real pointer activation and state assertions, with the embedding frame scrolled into view and the nested button focused first.
- The release workflow validates the tag, source identity, application versions and bilingual notes, runs the full test gate, and packages desktop and extension artifacts before publishing matching multi-architecture images to both registries.
