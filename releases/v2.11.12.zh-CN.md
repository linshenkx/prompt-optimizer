# Prompt Optimizer v2.11.12

## 概括
- 新增桌面端模型网络设置，解决公司模型接口需要直连、其他模型需要代理时的连接配置问题。
- 在「模型管理 → 网络设置」中统一选择跟随系统、直接连接或手动 HTTP 代理，并配置域名绕过规则。

## 亮点
- 一个桌面实例内的模型调用统一使用网络设置，覆盖模型列表获取、连接测试、提示词优化以及文本和图像生成。
- 支持精确域名和通配子域名绕过代理；本地及内网 IP 自动直连。
- 连接测试显示实际采用的直连、系统代理或手动代理路径，方便排查连接问题。

## 产品更新
### Desktop
- 在模型管理中增加网络设置入口，默认保持跟随系统。
- 手动代理支持无需认证的 HTTP 代理；跟随系统模式会按目标地址解析系统代理和 PAC 规则。
- 网络设置保存在本机，保存后重启桌面应用生效；模型请求进行中会阻止从设置窗口重启。
- 网络设置仅作用于模型请求，应用更新和云备份继续使用原有网络配置。

### Web
- 无功能变更。

### Extension
- 无功能变更。

### Core/Infra
- 简化 README 中重复的语言切换链接。

## 修复
- 允许公司模型接口通过直接连接或域名绕过规则避开系统代理，避免因代理路径不适用导致模型获取和连接失败（#364）。

## 破坏性变更 / 升级说明
- 无需迁移用户数据，现有模型配置保持可用；未修改网络设置时默认跟随系统。
- 公司模型均需直连时，可选择「直接连接」；需要同时使用外部代理时，可保留代理模式并添加公司模型的域名绕过规则。
- `*.company.com` 只匹配子域名，如需匹配 `company.com` 本身，请另加一条精确域名规则。
- 保存网络设置后需要重启。设置仅保存在本机，不包含在数据备份或模型配置导出中。
- 网页端和浏览器扩展不提供此设置；手动代理暂不支持代理认证和 SOCKS 配置。
