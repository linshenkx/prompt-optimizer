# Prompt Optimizer v2.15.0-beta.1

## 概括

本预览版新增竞技场：输入一份提示词及可选参考图片，在多个测试栏中并排比较文本或图像模型的回答。每栏独立选择连接和模型，支持单独测试或同时测试，并沿用已有的结果展示、会话恢复和备份功能。

## 亮点

- **同一输入，多模型对比**：自由增加测试栏，分别选择文本或图像生成模型；使用「测试全部」同时发起各栏请求，也可单独运行某一栏。
- **保留并排比较**：桌面多栏共享可用宽度，手机保持双栏同屏；更多测试栏可横向滚动，溢出时显示滚动条。
- **熟悉的操作方式**：输入、模型选择和结果区复用现有组件，继续使用预览、原文、复制、思考过程和全屏操作。
- **保留测试现场**：输入、模型选择和历史结果接入现有会话恢复；参考图片与生成图片沿用已有资产和备份机制。

## 产品更新

### Desktop

- 增加竞技场入口，通过现有桌面服务通道传递每栏选定的连接和模型。
- 各栏使用请求发起时的模型配置，切换测试模型不会改写共享连接配置。

### Web

- 增加竞技场工作区，将提示词、参考图片与公共操作集中到紧凑输入区。
- 支持桌面多栏、手机双栏及更多栏的横向滚动；每栏提供直接删除测试栏的操作。
- 切换工作区后请求继续执行，返回竞技场时可以继续查看结果。

### Extension

- 在扩展界面中增加共享的竞技场入口和测试栏。
- 沿用现有结果预览、原文、复制、全屏和空态组件。

### Core/Infra

- 增加请求级模型选择，在并行请求中保持各栏模型与输出相互独立。
- 将竞技场纳入 Session Manager、备份传输和图片资产维护。
- 区分文本与图像生成模型的类型名称和图标，保持共享选择器样式一致。

## 修复

- 整理竞技场输入区、模型操作与结果区布局，减少多余留白，并让窄栏控件适应可用空间。
- 在有横向溢出时显示滚动条，增加测试栏后将新栏滚动到可见位置。
- 统一各工作区的模型菜单和结果区，移除重复的作用范围及旧结果说明，保留已有保存有效性检查。
- 隔离停止后重试与迟到回调，避免旧请求覆盖新一轮结果。

## 破坏性变更 / 升级说明

- 本版本为体验和反馈用途的预发布版本，升级前可通过现有备份功能导出重要数据；既有工作区和备份格式继续沿用。
- 多栏测试会分别向所选模型发起请求，用量由各自的模型服务计费；停止能力沿用底层服务支持情况。
- 扩展数字版本为 `2.15.0`，显示版本为 `2.15.0-beta.1`。扩展 ZIP 供手动安装，本次发布不自动提交到扩展商店。
- Docker 镜像使用完整的 `2.15.0-beta.1` 标签；预发布不提升稳定镜像的 `latest`，也不改变桌面稳定更新渠道。

## 开发者说明

- 竞技场复用现有输入、模型选择、输出文档及图片资产组件，执行状态由会话层维护。
- 回归覆盖并行请求、列间模型隔离、停止后重试、迟到回调、刷新恢复和图片备份；现有 CI 同时执行工作区与扩展浏览器回归。
