# Prompt Optimizer v2.15.1

## 概括

本补丁修复功能模型选择框被挤成竖排的问题，同时收录 v2.15.0 之后已合入的共用 HTML/SVG 预览修复与 Prompt Garden 竞技场测评题集成。

## 亮点

- 恢复桌面与窄屏下功能模型选择框的正常宽度。
- 单个 HTML/SVG 预览充分使用全屏空间，并显示预览执行错误。
- 从 Prompt Garden 快速选用常见模型测评提示词，在竞技场中比较模型表现。

## 产品更新

### Desktop

- 应用共用模型选择框布局与 HTML/SVG 预览改进。

### Web

- 在竞技场增加测评题入口，支持从 Prompt Garden 导入所选示例的变量及参考图片。
- 导入时保留测试栏和已有结果，不自动发起模型请求。

### Extension

- 应用共用选择框与预览改进，支持显示打包预览页面报告的错误。

### Core/Infra

- Garden 导入与结果显示沿用已有会话和预览组件。

## 修复

- 为功能模型选择框提供稳定的布局容器，确保宽度样式生效，并让占位文本保持单行。
- 识别独立 SVG 文档及 SVG 代码块，让固定尺寸图形适应预览区域。
- 让单个 HTML/SVG 内容在全屏时使用可用空间。
- 显示预览脚本、模块、资源及未处理 Promise 报告的错误，并校验消息来源和预览版本。

## 破坏性变更 / 升级说明

- 无破坏性变更，无需迁移备份格式。
- 扩展 ZIP 版本为 `2.15.1`，继续供手动安装，本次不提交扩展商店。
- 桌面发布进入稳定更新渠道；Docker 发布 `2.15.1`，验证后将同一镜像提升为两个仓库的 `latest`。

## 开发者说明

- 选择框修复已通过 16 项已有组件测试、UI 构建、代码检查，以及桌面和 390px 窄屏的实际页面检查。
- 共用预览与 Garden 导入变更在准备本补丁版本前已通过 master 上的现有 CI。
- 发布流程执行现有仓库与浏览器门禁，从同一标签提交构建桌面、扩展及双仓库多架构镜像，全部成功后再公开版本。
