# Prompt Optimizer v2.16.1

## 概括

工作区会在编辑时自动保存，刷新后可以接着编辑。测试结果会保留模型报告的 token 用量，也可以把多列测试结果一次收藏。

## 亮点

- 刷新页面或重开桌面应用后，继续编辑上次的工作区草稿。
- 重新打开文本测试结果和竞技场时，仍可查看模型报告的 token 用量。
- 桌面宽度的测试区可点「测试全部」旁的星标批量收藏。同一提示词的结果可以存到同一个收藏，不同提示词的结果会分组保存。

## 产品更新

### Desktop

- 关闭桌面应用或安装更新前，先保存工作区中尚未写入的草稿。

### Web

- 单列收藏使用该次测试保存的提示词和输入。编辑工作区后，之前的测试结果仍可收藏。
- 批量收藏不同提示词的结果时，可勾选要保留的结果，确认后为各组分别新建收藏。 [#381](https://github.com/linshenkx/prompt-optimizer/pull/381)

### Extension

- 浏览器扩展刷新后可恢复工作区草稿，以及模型返回的文本测试 token 用量。

### Core/Infra

- 统一读取受支持文本模型返回的 token 用量，覆盖非流式结果。 [#379](https://github.com/linshenkx/prompt-optimizer/pull/379)
- 补充 Claude 模型选项，并识别更多支持自适应思考的模型 ID。 [#380](https://github.com/linshenkx/prompt-optimizer/pull/380)

## 修复

- 修复刷新页面、切换工作区前的最新编辑可能丢失的问题。
- 收藏测试结果时保留该列当时的输入，避免工作区后续编辑影响已保存的示例。

## 破坏性变更 / 升级说明

- 升级后可以继续使用已有的模型配置、工作区会话和收藏。
- 扩展 ZIP 内版本为 `2.16.1`，可手动安装。
