# Prompt Optimizer v2.17.0-beta.4

## 概括

使用桌面或已连接网页中配置的模型，对照测试提示词。

## 亮点

一组可以测试 2–4 个候选。可以让多个模型回答同一道题，也可以固定模型比较不同版本的提示词。

## 产品更新

顶部「MCP 运行成果」支持并排查看每个候选的输入、变量、模型、原始回答和推理过程。

## 修复

Magpie 等已配置的提供商现在通过产品的普通文本测试执行对照。

## 破坏性变更 / 升级说明

产品 MCP 精简至 15 个工具。调用旧 Beta 的 12 个比较工具的客户端需要改用 `po_query` 和 `po_runs_*`。配套 npm 包版本为 `0.2.0-beta.3`，请同步更新包内的对照 Skill。

## 开发者说明

归档可以直接通过原 ID 打开旧版比较，沿用现有存储格式和备份字段。
