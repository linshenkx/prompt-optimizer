# Prompt Optimizer v2.17.0-beta.3

## 概括

现在可以在 MCP 客户端里使用保存在 Prompt Optimizer 中的模型和提示词。默认读取当前用户的桌面资料，也可以选择某个浏览器资料来优化提示词、运行测试和对比已保存的结果。

## 亮点

- 关闭桌面窗口后仍可读取桌面模型和收藏。可以用一个已保存的模型优化提示词，再用另一个模型测试优化结果。
- 两个浏览器访问同一网址时可分别授权、选择资料。断开后重新授权原资料，即可继续读取之前保存的内容。

## 产品更新

### Desktop

Windows 安装包内置 MCP 服务。在帮助菜单选择 **Copy Codex MCP Configuration**，即可复制包含本机程序和资料路径的配置。连接可按需申请只读或读写权限。

### Web

使用已部署本版浏览器桥的网页，例如自行部署的 beta 站点。在目标浏览器资料中打开一次性授权链接，使用期间保持该标签页开启。

### Extension

含已保存比较或桌面运行记录的备份需要在桌面端恢复。向网页版迁移时也适用这一限制。

### Core/Infra

npm beta 包新增 `prompt-optimizer-product-mcp` 入口，并保留原有的 `prompt-optimizer-mcp` 命令。两个入口随同一个自包含包分发。

## 修复

关闭已授权的标签页后，原连接随即失效。同一网址存在多份浏览器资料时，显式指定来源可确保操作落在选中的资料上。

## 破坏性变更 / 升级说明

从 beta.2 升级会继续使用现有桌面 SQLite 数据库。建议升级前备份桌面资料。桌面图片和完整数据包操作需要打开桌面界面。

## 开发者说明

独立 MCP beta 可通过 npm 安装。使用 Node.js 24.22.1 或更高的 24.x 版本，在 MCP 客户端配置以下命令。Windows 请使用 `npx.cmd`。

```sh
npx --yes --package=@prompt-optimizer/mcp-server@beta prompt-optimizer-product-mcp
```

按需追加 `--desktop-profile=<路径>` 或 `--product-url=<网址>` 即可更改默认资料来源。
