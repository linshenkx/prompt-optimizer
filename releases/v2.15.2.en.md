# Prompt Optimizer v2.15.2

## Summary

This patch restores automatic wrapping and Stop controls for streaming output, updates two security-sensitive dependencies, and includes Garden browsing improvements and optional GPT Image 2.6 GIF output added since v2.15.1.

## Highlights

- Read long streamed responses and source views without horizontal overflow.
- Stop an individual text stream in ordinary workspaces and fullscreen views.
- Search and browse Garden inspiration and Arena evaluation prompts in place.
- Select GIF output for compatible GPT Image 2.6 endpoints while retaining PNG as the default.

## Product Updates

### Desktop

- Apply the shared output, Garden browsing and image-output improvements.

### Web

- Switch between recommended and all Garden prompts, search the catalog, load additional results and retry failed requests.
- Preserve browsing position and loaded results when closing and reopening the popover in the same workspace and language.

### Extension

- Apply the shared output and Garden browsing improvements.

### Core/Infra

- Preserve animated GIF data through image previews, storage and downloads. Compatible endpoints can use optional frame-count and frame-delay parameters.
- Pin Vue I18n to 11.4.14 and override transitive Hono Node Server to 2.1.3, including its MCP SDK dependency path.

## Fixes

- Enable CodeMirror line wrapping for streamed and read-only source output, including long paragraphs and URLs. Fixes [#374](https://github.com/linshenkx/prompt-optimizer/issues/374).
- Restore the default Stop-button policy through embedded, fullscreen and core output components. Explicitly disabled channels, including non-cancellable Arena channels, remain disabled.
- Include the output architecture regressions in the daily browser gate so optimization history, independent cancellation, terminal-state persistence and concurrent rendering are checked continuously.
- Improve Garden image cards, source expansion, responsive popover sizing and pagination recovery.
- Update Vue I18n and Hono Node Server to the patched releases for [GHSA-83rm-6c8r-g728](https://github.com/advisories/GHSA-83rm-6c8r-g728), [GHSA-8rc2-428q-7ww3](https://github.com/advisories/GHSA-8rc2-428q-7ww3) and [GHSA-rmxm-3fg6-px4f](https://github.com/advisories/GHSA-rmxm-3fg6-px4f).

## Breaking Changes / Upgrade Notes

- No breaking changes or backup-format migration.
- Garden catalog browsing requires a Garden service with the public catalog endpoint. GIF generation requires an endpoint that supports the requested format and optional animation parameters.
- Extension ZIP version is `2.15.2`; installation remains manual, without an extension-store submission.
- The stable release workflow builds desktop, extension and Docker images from the same tagged commit. Stable Docker aliases are promoted only after the image checks succeed.

## Developer Notes

- Browser coverage includes 1440px and 390px output layouts, streaming and completed source views, long URLs, the final line and exact source copying.
- Cancellation unit coverage checks omitted and explicitly disabled settings through both output wrappers. Existing browser regressions retain optimization-history and cancellation assertions.
- The release workflow runs repository, core, UI, Web and browser gates before publishing. Simulated CPU throttling and background/freeze tests do not replace acceptance on every native desktop or low-end device.
