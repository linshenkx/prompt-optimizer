# Prompt Optimizer v2.17.0

## 概括

在新的「视频」工作区写下创作要求，按需添加参考图，即可生成视频提示词。你可以直接编辑草稿，也可以提出修改意见继续迭代。在网页和桌面版，还可以生成视频，并排查看改写前后的效果。

## 亮点

- 支持通过火山方舟或 BytePlus ModelArk 使用 Seedance，也支持 MiniMax 海螺。根据模型能力，可以使用纯文本、指定首帧并按需添加尾帧，或提供多张参考图。
- 支持两到四栏对比。可以固定模型比较不同版本的提示词，也可以用一段提示词比较多个模型。每栏可单独调整时长等参数，提交前可核对本次要运行的各栏。

## 产品更新

- 刷新后，视频工作区会继续跟踪进行中的任务，并显示各栏最近一次完成的结果。成片可在服务商链接过期前下载。浏览器扩展支持编写和迭代视频提示词。
- 多图工作区支持一次拖入多张图片，再拖动缩略图调整顺序。优化前可以查看预计上传大小。图片较大时，应用按需缩小本次请求中的图片副本，原始参考图保留在工作区。

## 修复

- 多图优化在收到新输出前取消或出错时，会保留上一次的结果。
- 提示词历史达到保留上限时，仍可从保留下来的版本沿着迭代记录回看，直到这条提示词的初始版本。

## 破坏性变更 / 升级说明

- 从 v2.16.2 或更早版本升级后，首次启动桌面版会自动将模型配置、模板、历史记录、收藏和工作区草稿迁移到 `prompt-optimizer-data.sqlite`。如果已在测试版完成迁移，正式版会直接使用同一个数据库。
- 原有的 `prompt-optimizer-data.json` 保留着迁移时的数据，之后的更改写入 SQLite。如果你过去通过复制 JSON 文件备份数据，今后可从顶部工具栏的「数据管理」导出最新备份。

## 开发者说明

桌面端在同一个 SQLite 事务中导入旧数据并记录迁移完成状态。如果导入中断，下次启动时可以重试。
