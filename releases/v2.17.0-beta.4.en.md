# Prompt Optimizer v2.17.0-beta.4

## Summary

Run prompt comparisons with configured models from the desktop or a connected browser.

## Highlights

Each batch can test two to four candidates. Compare multiple models on one saved prompt or try different prompts with one model.

## Product Updates

Open saved batches in **MCP results** to see input, variables, model, output and reasoning for each candidate.

## Fixes

Magpie and other configured providers now use the same text test as the workspace.

## Breaking Changes / Upgrade Notes

The product MCP now exposes 15 tools. Replace the 12 beta comparison tools with `po_query` and `po_runs_*`. Update the MCP package to `0.2.0-beta.3` and refresh its bundled comparison Skill.

## Developer Notes

The archive reads earlier saved comparisons by their original IDs. Existing backup sections and storage formats are preserved.
