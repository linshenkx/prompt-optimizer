# Prompt Optimizer v2.12.0-beta.1

## 概括
- 这是移动端与 PWA 的首个预览版本，供希望提前体验的用户验证真实设备上的使用流程；稳定版渠道保持独立。
- 新增七个工作区的移动端布局，以“优化 / 测试”两个区域组织操作，保留提示词上下文并支持结果并排对比。
- 为模型、历史、模板、变量、收藏和数据管理提供适合手机的列表、详情和编辑布局。
- Web 生产版本支持安装为 PWA、离线打开已保存的本地工作，以及保存后更新；加强工作区恢复和跨窗口写入保护。

## 亮点
- 原稿与优化稿在同一区域查看，配置和工具栏按可用空间调整，减少多层标签切换，把空间留给正文。
- 测试时可查看实际提示词来源并同时比较结果；长文本、图片预览和键盘弹出后的操作区域得到优化。
- 手机应用外壳复用原有业务组件和数据服务，桌面宽屏继续使用既有分栏与操作方式。

## 产品更新
### Web
- 覆盖基础系统、基础用户、上下文多消息、上下文变量、文生图、图生图和多图生图七个工作区。
- 重新组织移动端功能菜单和模式选择：模式集中展示，选择具体模式后再进入；管理页支持列表、详情、编辑及返回工作区。
- 优化手机模型表单、历史恢复、模板编辑、变量导入、收藏分类与标签，以及数据导入导出操作。
- 新增安装提示、独立窗口外观、离线状态提示和“保存并更新”。生成、评估、未保存管理表单或保存失败时阻止更新；存在同作用域其他窗口时提示关闭后重试。
### Core/Infra
- 备份与恢复纳入七类工作区快照及关联图片，支持通过现有导出导入流程迁移到新的访问地址。
- 加强工作区条件写入、损坏快照条件清理、图片清理协调和移动端延后保存，避免旧窗口覆盖新内容。

## 修复
- 修复另一个窗口仅初始化默认值时，“保存并更新”误报工作区写入冲突的问题；真正的并发编辑仍会受到保护。
- 修复评估面板关闭后，请求尚未结束却允许应用更新的问题。
- 修复移动端保存遇到临时忙碌后遗漏后续保存，以及快速编辑消息后保存未包含最后输入的问题。
- 修复手机键盘遮挡选择菜单、配置区编辑期间自动折叠、重复选择当前供应商导致模型配置被清空等问题。
- 优化正文末尾阅读、工具栏占位、图片对比和移动弹窗的滚动布局。
- 修复继续优化失败后原有提示词未正确恢复的问题。
- 修复 Docker 公共构建资源的缓存策略和 Manifest 类型，使符合安装条件的部署可完成 PWA 安装；继续保护配置、API、鉴权响应及错误响应。

## 破坏性变更 / 升级说明
- 现有访问方式和桌面操作继续可用，无需手动转换工作区数据。移动端评估界面不在本轮新增范围内。
- PWA 适用于 Web 生产构建，需要可信 HTTPS 或浏览器认可的 localhost。普通局域网 HTTP IP 可在线使用，但不满足完整 PWA 安装条件。
- Android Chrome 可通过浏览器安装入口添加应用；iOS Safari 可通过“分享 → 添加到主屏幕”操作。本轮真机验收覆盖 Android，未完成 iOS 真机验收。
- 离线能力用于打开、阅读和编辑已经保存的本地工作；模型推理、首次加载和在线配置获取仍需要联网。PWA 不是原生 APK，也不提供离线模型。
- Docker 设置 `ACCESS_PASSWORD` 时仍要求登录，支持在线使用，不支持离线外壳安装。无需为安装而放开受保护入口。
- 浏览器按来源隔离数据：域名、协议或端口变化不会自动迁移旧数据。切换到新 HTTPS 地址前，通过数据管理导出含资源的备份，再在新地址导入。
- 更新提示出现时先结束运行中的任务、处理未保存表单，并关闭同一应用的其他窗口，再选择“保存并更新”；真实冲突时先保留本地草稿，不要强行覆盖。
- 开发热更新、Electron 和浏览器扩展不注册此 Service Worker。反向代理需保留公共静态资源与私有运行数据的缓存边界。

## 开发者说明
- 预览版统一通过 Release 流程构建各端与 Docker 镜像，绑定同一版本和源码提交；预览镜像只提供完整版本标签，不更新稳定版 latest。
- 移动布局和样式按呈现职责组织；七个工作区共享分栏、测试组绑定、来源预览、批量测试等编排能力，具体模型与业务规则继续由各模式负责。
- PWA 位于 Web 包，通过应用更新准备接口调用共享 UI，不直接操纵内部工作区 Store。
- 回归覆盖接入现有 CI 入口，包括 Web/PWA、条件存储写入、损坏快照清理、延后保存、七工作区手机/桌面浏览器行为，以及 Docker HTTP 策略。
- 本地预览模型网关为显式启用的开发工具，正式版本不内置测试用 Magpie 服务或免费模型凭据。
- 安装与缓存边界详见 [PWA 技术说明](../packages/web/PWA.md) 和 [Docker 部署说明](../mkdocs/docs/zh/deployment/docker-basic.md)。
