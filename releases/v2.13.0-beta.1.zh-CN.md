# Prompt Optimizer v2.13.0-beta.1

## 概括

本预览版支持在 Markdown 结果中直接交互 HTML 网页，并重构输出链路，以应对并发生成和长内容。同步增强备份完整性，新增指定云备份的导入码，修复模型选择与已保存参数的保留问题，完善图片编辑和结构化输入模板。

## 亮点

- **网页就地交互**：通过“预览 / 原文”查看结果，显式 HTML 代码块及支持的 HTML 内容会在周围 Markdown 之间显示为独立网页，多个块可同时交互。
- **限制输出与渲染开销**：生成过程使用独立输出文档、虚拟化原文视图和后台 Markdown 解析。内容过大或渲染过重时回退到原文显示，避免无限扩展渲染页面。
- **更可靠的备份恢复**：恢复前校验数据和图片资源，保护已有图片不被自动淘汰，并在前置导入步骤成功后才恢复工作区快照。
- **云备份导入码**：为选定的 WebDAV、S3 兼容或 Cloudflare R2 备份生成导入码、链接，并在长度允许时生成二维码。

## 产品更新

### Desktop

- 将取消生成从界面经桌面通信传递到模型请求，流式完成会等待异步收尾操作。
- 接入统一的“预览 / 原文”结果界面、就地 HTML 预览与备份导入码流程。

### Web

- Markdown 中的多个 HTML 示例直接显示为网页，无需切换到独立的网页预览模式。将某一列切到原文，不会重建其他列的预览。
- 生成期间显示原文，生成完成后才创建可执行的网页预览。
- 允许预览网页请求外部数据，同时保持与主应用隔离；请求仍受浏览器跨域规则和目标接口授权要求约束。

### Extension

- 扩展构建包含共用的输出与备份改进。
- 已知限制：扩展的内容安全策略会拦截 HTML 预览中的内联脚本，本 beta 不支持在扩展内交互生成的网页，请使用 Web 版体验此功能。
- 本次手动安装的预览包使用数字版本 `2.13.0`，显示版本为 `2.13.0-beta.1`。

### Core/Infra

- 将逐片生成的文本与响应式工作区快照解耦，在明确的完成边界统一写入完整或中断结果。
- 对输出大小、渲染量和待处理队列设置预算，并取消过时的解析任务。
- 将取消信号贯穿 OpenAI 兼容、Anthropic 和 Gemini 流式适配器。

## 修复

- 支持单独输出的 HTML 按钮等控件进入网页预览，并修复手机窄列对比时工具栏按钮越界的问题。
- 在写入新的业务引用前，拒绝无效备份数据、图片资源冲突和图片存储容量不足的恢复操作；明确报告部分恢复与回滚失败，避免将未完成恢复显示为成功。
- 完善设置和图片引用的导出与恢复，工作区恢复保持为最终导入步骤。
- 刷新模型列表时保留当前选择，包括返回空列表和使用回退列表的情况。
- 模型参数定义更新时保留已保存的参数，并按适用定义校验用户修改的值。
- 图片模板更明确地区分参考图作用、编辑范围和需要保留的内容；保留结构化 JSON 的字段、类型、控制值和占位符。
- 更新备份与桌面通信回归测试，使其覆盖新的预校验、存储和取消接口。
- 将 Zod、body-parser、qs 及构建工具使用的 Undici 6 更新至修补版本，处理近期公布的依赖安全告警。

## 破坏性变更 / 升级说明

- 本版本为**试用预览版**。在重要工作区使用前，请先导出备份。
- 仅供构建使用的 deepmerge 仍有一项上游尚未修补的低危告警；已确认的调用路径用于合并受信任的 Rollup 配置，不进入应用运行时。
- 云备份导入码包含存储访问凭据，不是权限受限的公开分享链接，请只交给可信的接收者。本版本不支持为 Google Drive 导出备份导入码。
- HTML 脚本在独立 iframe 中运行。隔离可以保护主应用文档并限制权限，但不会为任意生成脚本设置 CPU 或内存硬配额。WebGPU 等能力还取决于浏览器和设备。
- 超出输出或渲染预算时，可能停止生成或改用原文显示；中断结果与正常完成结果会保持区分。
- 预览 Docker 镜像只使用明确的 `2.13.0-beta.1` 标签，不替换稳定版 `latest` 镜像或 GitHub 最新正式版。桌面端预发布更新仍需用户主动选择。
- 扩展预览包与后续 `2.13.0` 正式包使用相同数字版本，不保证预览之间或预览到正式包的自动升级顺序。

## 开发者说明

- 回归覆盖并发生成、取消、恢复失败、原文回退、渲染预算与标签页生命周期。CPU 降速属于模拟，不能替代低性能硬件上的实际测试。
- 发布流程校验标签和各端版本，执行测试门禁，构建桌面与扩展安装包，并在带版本号的多架构 Docker 镜像发布成功后，公开 GitHub 预发布版本。
