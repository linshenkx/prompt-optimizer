# Prompt Optimizer v2.15.0-beta.1

## Summary

This preview adds Arena: enter one prompt and optional reference images, then compare responses from text or image models in parallel test columns. Each column selects its own connection and model, supports individual or batch testing, and reuses existing output, session recovery and backup features.

## Highlights

- **One input, multiple models:** add independent test columns for text or image generation. Run all selected columns together, or test one column individually.
- **Keep comparisons side by side:** desktop columns share the available width, while phones retain two visible columns. Additional columns scroll horizontally, with a visible scrollbar when needed.
- **Familiar controls:** reuse existing input, model selection and result components, including Preview, Source, Copy, reasoning display and fullscreen controls.
- **Recover your tests:** restore inputs, model choices and previous results through existing sessions. Reference and generated images use the shared asset and backup mechanisms.

## Product Updates

### Desktop

- Add the Arena entry and forward each column's selected connection and model through the existing desktop service bridge.
- Capture the selected model configuration for each request without rewriting shared connection settings when switching test models.

### Web

- Add an Arena workspace with the prompt, reference images and shared actions in a compact input area.
- Support desktop columns, a two-column phone layout and horizontal scrolling for additional columns, with a direct delete action for each test column.
- Continue requests across workspace navigation so results remain available when returning to Arena.

### Extension

- Add the shared Arena entry and test columns to the extension interface.
- Reuse existing Preview, Source, Copy, fullscreen and empty-state components.

### Core/Infra

- Add request-local model selection to keep concurrent columns' model choices and outputs independent.
- Integrate Arena with Session Manager, backup transfer and image asset maintenance.
- Identify text and image generation models with type labels and icons while retaining the shared selector style.

## Fixes

- Organize Arena's input, model actions and results to reduce excess whitespace and fit controls into narrow columns.
- Show a scrollbar when columns overflow and bring newly added columns into view.
- Unify model menus and result panels across workspaces by removing redundant scope and previous-result copy while retaining save-validity checks.
- Isolate retries and late callbacks so a stopped request cannot overwrite a newer result.

## Breaking Changes / Upgrade Notes

- This is a prerelease for trying the feature and providing feedback. Important data can be exported with the existing backup tools before upgrading; existing workspaces and backup formats are retained.
- Each test column makes its own model request, billed by the selected service. Cancellation follows the underlying service's capabilities.
- The extension uses numeric version `2.15.0` and display version `2.15.0-beta.1`. Install the ZIP manually; this release does not submit an extension-store update.
- Docker images use the full `2.15.0-beta.1` tag. This prerelease does not promote stable `latest` image tags or change the stable desktop update channel.

## Developer Notes

- Arena reuses existing input, model selection, output document and image asset components, with execution state managed by the session layer.
- Regression coverage includes concurrent requests, model isolation, retries after cancellation, late callbacks, refresh recovery and image backups. Existing CI also runs workspace and extension browser regressions.
- Arena-specific end-to-end acceptance on native Electron, physical phones and real image providers remains unverified; preview feedback will help validate those surfaces.
- The release workflow builds desktop, extension and matching multi-architecture images for both registries from the same versioned commit, then publishes the prerelease after all required tasks succeed.
