# Prompt Optimizer v2.16.0

## 概括

选模型时就可以调整该模型支持的思考强度和其他参数。要比较同一个模型的不同设置，可以用同一道题分别运行并查看结果。本版也恢复了思考内容的显示和换行，并更新了项目文档。

## 亮点

- 在模型下拉框内选择模型并调整可用的思考设置。
- 各工作区和竞技场测试栏从已保存的模型默认值继承参数，也可以独立调整。
- 生成时即可阅读模型返回的思考内容，生成完成后也能展开查看。

## 产品更新

### Desktop

- 文本和图像模型下拉框显示简洁的参数摘要，展开后可调整所选模型支持的设置。

### Web

- 竞技场中，同一个模型可以使用多组参数测试。各测试栏用自己的设置运行同一份输入。
- 官网和 README 更新了产品截图。文档首页提供接入模型、选择工作区和对比改写效果的直接入口。

### Extension

- 可在模型菜单调整受支持的开关、选项或数值，也可以用重置操作恢复已保存的默认值。

### Core/Infra

- 文本和图像请求按当前选择应用独立参数，并继承已保存配置中兼容的参数。

## 修复

- 模型返回思考内容时，在支持的工作区和竞技场恢复显示。生成中和生成完成后的长行都能自动换行。
- 修复中文标点位于 Markdown 加粗片段末尾时无法正确渲染的问题。

## 破坏性变更 / 升级说明

- 升级后，已有的模型配置仍作为各工作区的默认值。
- 浏览器扩展 ZIP 版本为 `2.16.0`。

## 开发者说明

- 参数测试覆盖同一模型的多组独立设置、参数继承与恢复，以及已保存的文本和图像模型选择。
- 思考内容浏览器回归覆盖用户提示词工作区和竞技场，检查生成中、生成完成以及页面刷新后的显示。
