# Prompt Optimizer v2.13.0-beta.1

## Summary

This preview release introduces interactive HTML blocks inside Markdown results and a redesigned output pipeline for concurrent generation and large responses. It also improves backup integrity, adds import codes for selected cloud backups, preserves model selections and saved parameters, and refines image-editing and structured-input templates.

## Highlights

- **Interactive output in place:** use Preview or Source to inspect results. Explicit HTML code blocks and supported HTML content render as isolated web pages alongside the surrounding Markdown. Multiple blocks can remain interactive at the same time.
- **Bounded streaming and rendering:** generation uses a dedicated output document, virtualized source views and background Markdown parsing. Oversized or expensive content falls back to source instead of building an unbounded rendered page.
- **More reliable backups:** validate data and image resources before restoration, protect existing images from eviction, and restore workspace snapshots only after preceding import steps succeed.
- **Cloud backup import codes:** transfer a selected WebDAV, S3-compatible or Cloudflare R2 snapshot using a code, link or QR code when its size permits.

## Product Updates

### Desktop

- Propagate cancellation from the interface through desktop IPC to model requests. Streaming completion now waits for asynchronous completion work.
- Use the shared Preview/Source output interface, inline HTML previews and backup import-code flow.

### Web

- Render multiple HTML examples directly in Markdown results without a separate web-preview mode. Switching one result to Source leaves other results' previews intact.
- Keep in-progress responses in the source view; executable previews are created after generation completes.
- Allow HTML previews to request external data while retaining isolation from the application. Requests remain subject to browser CORS rules and the target service's authorization requirements.

### Extension

- Include the shared output and backup improvements in the extension build.
- Known limitation: the extension's content security policy blocks inline scripts in HTML previews. Interactive generated pages are not supported in the extension in this beta; use the Web version for this feature.
- Use manifest version `2.13.0` with display version `2.13.0-beta.1` for this manually installed preview package.

### Core/Infra

- Separate streaming text from reactive workspace snapshots and publish final or interrupted results at explicit completion boundaries.
- Apply output-size, rendering and queue budgets, and cancel obsolete parsing work.
- Carry cancellation signals through OpenAI-compatible, Anthropic and Gemini streaming adapters.

## Fixes

- Preview standalone HTML controls such as buttons, and keep output-toolbar actions within narrow mobile comparison columns.
- Reject invalid backup sections, conflicting image resources and insufficient image-storage capacity before publishing new references. Report partial restoration and rollback failures instead of presenting incomplete work as success.
- Preserve relevant settings and image references across export and import. Keep workspace restoration as the final import step.
- Preserve the selected model when refreshing lists, including empty responses and fallback lists.
- Preserve saved model parameters when provider definitions change, while validating edited values against applicable definitions.
- Clarify reference-image roles, edit scope and preservation requirements in image templates. Keep structured JSON fields, types, control values and placeholders intact.
- Update backup and desktop communication regression coverage for the new validation, storage and cancellation interfaces.
- Update Zod, body-parser, qs and the build tooling's Undici 6 dependency to patched versions for recently disclosed security advisories.

## Breaking Changes / Upgrade Notes

- This is a **prerelease for evaluation**. Export a backup before trying it with important workspaces.
- The build-only deepmerge dependency still has an unpatched low-severity advisory; the identified path merges trusted Rollup configuration and is not part of the application runtime.
- Cloud backup import codes contain storage access credentials; they are not limited-permission public links. Share them only with trusted recipients. Google Drive import-code export is not supported in this release.
- HTML scripts execute inside isolated iframes. Isolation protects the application document and restricts permissions, but it does not impose a hard CPU or memory quota on arbitrary generated scripts. WebGPU and other browser features depend on the browser and device.
- Content that exceeds output or rendering budgets may stop generation or display as source. A stopped response remains distinguishable from a completed response.
- Preview Docker images use only the explicit `2.13.0-beta.1` tag. Stable `latest` images and the latest stable GitHub release are not replaced. Desktop prerelease updates remain opt-in.
- Extension preview packages share the numeric version of the eventual `2.13.0` release; automatic upgrade ordering between previews and the stable package is not guaranteed.

## Developer Notes

- The output pipeline uses bounded documents, CodeMirror source views, one shared Markdown worker and separate iframe previews. See [Output pipeline architecture](https://github.com/linshenkx/prompt-optimizer/blob/v2.13.0-beta.1/docs/architecture/output-pipeline.md).
- Regression coverage includes concurrent producers, cancellation, restoration failures, source fallback, rendering budgets and tab lifecycle behavior. CPU throttling is a simulation, not a substitute for testing on low-performance hardware.
- The release workflow validates the tag and package versions, runs the test gates, builds desktop and extension packages, and publishes versioned multi-architecture Docker images before making the GitHub prerelease public.
