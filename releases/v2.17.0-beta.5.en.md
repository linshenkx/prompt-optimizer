# Prompt Optimizer v2.17.0-beta.5

## Summary

The new Video workspace turns a brief into a prompt you can edit, refine and test. On web and desktop, compare clips from different prompts or video models side by side.

## Highlights

- Generate with Seedance through Volcengine Ark or BytePlus ModelArk, or with MiniMax Hailuo. Depending on the model, start from text, a first and optional last frame, or reference images.
- Compare two to four columns. Share settings such as duration across compatible models, or set them independently to see how one change affects the result. Review the selected runs before confirming generation.

## Product Updates

- After a reload, the workspace resumes tracking active tasks and shows the latest finished result in each column. Play a clip in its column or download a copy before the provider link expires. The browser extension supports writing and refining video prompts. Use web or desktop to generate clips.
- Multi-image optimization shows the estimated image payload size and resizes copies for the request when needed. The workspace keeps the reference images and their order for later edits.

## Fixes

- Cancelling a multi-image optimization or encountering an error before new output arrives preserves the previous result.
- The video model selector shows the model ID. A submitted task keeps its original account, model and settings when you change the next test.

## Breaking Changes / Upgrade Notes

If your MCP client used a server executable bundled with the desktop app, change its stdio launch command to `npx -y @prompt-optimizer/mcp-server@0.2.0-beta.4` with Node.js 24, 25 or 26. The server reads the local desktop profile by default. To use browser data, authorize the connection in the browser profile that holds it.

Open earlier comparisons in your MCP client using `po_runs_list` and `po_runs_get`. MCP run archives stay in their source profile. Restoring a mixed backup from an earlier beta imports the product data and skips the MCP archive. To include an optimized prompt in a product backup, save it to History or Favorites.

## Developer Notes

The Docker image continues to serve the three prompt optimization and iteration tools over Streamable HTTP at `/mcp`, using the container's model configuration. [Docker MCP guide](https://github.com/linshenkx/prompt-optimizer/blob/v2.17.0-beta.5/docs/user/mcp-server_en.md)
