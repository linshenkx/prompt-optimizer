# Prompt Optimizer v2.14.0-beta.1

## 概括

本预览版新增本机服务发现与模型连接引导，统一工作区控件和模型选择，整理数据管理及云备份流程。同步增加提示词来源悬浮预览，修复配置字段无法可靠清空、分类父级清空，以及延迟悬浮预览遮挡全文弹窗的问题。

## 亮点

- **发现本机模型服务**：文本模型管理器识别支持且可访问的服务，通过快捷入口打开现有连接编辑器，并提供对应服务的配置引导。
- **更清晰的工作区控件**：统一图标、紧凑的来源和模型选择器，以及响应式工具栏，让配置和输出操作更容易找到。
- **查看实际测试的提示词**：桌面布局支持悬浮阅读来源内容，也可直接打开全文。来源标签和模型选择与对应工作区保持一致。
- **整理数据管理**：通过独立区域查看本机占用、导出或恢复本地文件、管理云端备份，并明确展示连接与加载状态。

## 产品更新

### Desktop

- 通过桌面桥接执行受限制的本机服务探测，并提供模型连接引导。
- 保存模型配置时，通过桌面通信正确传递显式清空的字段。
- 接入统一的工作区、来源预览和数据管理调整，包括云备份连接凭据持久化，以及只读连接检查和列表读取。

### Web

- 发现支持且可访问的 Ollama、Magpie、CLIProxyAPI、LiteLLM 和 llama.cpp 服务；浏览器提供所需能力时，可使用 Chrome AI 入口。
- 预填连接草稿并提供服务配置说明。模型刷新、凭据输入、模型选择和保存仍由用户明确执行。
- 对已经配置的本机地址去重，并保持各工作区的模型选择相互独立。
- 在统一的响应式数据管理界面中展示本机数据、本地文件和云端备份。

### Extension

- 在扩展界面中使用更新后的工作区控件、模型选择器和提示词来源预览。
- 保持多个就地 HTML 预览在预览/原文切换及页面生命周期变化中的独立交互状态。
- 完善窄屏操作，以及共用的数据管理和备份控件。

### Core/Infra

- 增加本机服务识别、模型目录转换和 Magpie 适配器。
- 在 IPC 序列化和模型更新处理中保留显式清空的配置值。
- 补充本机发现、连接草稿、工作区模型隔离、备份流程和来源预览交互的回归覆盖。

## 修复

- 正确保存清空后的分类父级，支持将分类移回顶级。
- 通过桌面服务桥接保留明确清空的模型配置字段，包括 API Key。
- 在来源菜单关闭、Escape 取消待显示预览或打开提示词全文后，忽略过期的悬浮回调，避免预览再次弹出并遮挡弹窗控件。
- 恢复清晰的提示词来源标签，保持工作区模型选择独立，并让紧凑操作标签适应可用空间。
- 持久保存云备份凭据，刷新出错时保留已有列表，并忽略被新连接配置或授权替代的旧响应。
- 云端连接检查和目录查找保持只读，创建备份和恢复数据仍是独立操作。

## 破坏性变更 / 升级说明

- 本版本为测试用途的预发布版本，升级前建议导出重要应用数据。既有备份格式和远程目录继续沿用。
- 本机发现不会读取或创建 API Key、自动导入模型或发送推理请求。需要授权的服务仍须使用用户自己的客户端密钥，浏览器访问也受跨域和本地网络访问规则约束。
- 本预览版未提供 LM Studio 和 CC Switch 的自动发现入口，兼容服务仍可通过模型编辑器手动配置。
- 扩展使用数字版本 `2.14.0` 和显示版本 `2.14.0-beta.1`，请手动安装 ZIP；本次发布不会自动向浏览器扩展商店提交更新。
- Docker 镜像使用完整的 `2.14.0-beta.1` 标签，本预发布不会提升稳定镜像的 `latest` 标签或桌面稳定更新渠道。

## 开发者说明

- 服务发现通过现有模型编辑器和持久化流程提供连接草稿，不会自动注册服务或导入模型目录。
- 备份测试覆盖凭据持久化、只读连接、配置草稿、导入码归属和过期响应处理；模拟授权不等于真实账号的 OAuth 授权验收。
- 来源预览回归覆盖七种工作区模式，以及快速选择来源后打开全文的场景。扩展安装包测试继续使用真实鼠标操作和状态断言，先滚动外层预览到可见位置，再聚焦内部按钮。
- 发布流程校验标签、源码身份、各端版本和中英文说明，执行完整测试门禁，在桌面与扩展产物完成后向两个仓库发布一致的多架构镜像。
