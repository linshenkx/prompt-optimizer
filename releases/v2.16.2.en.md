# Prompt Optimizer v2.16.2

## Summary

New OpenAI-compatible image model configurations use the provider's defaults for optional settings. This improves compatibility with gateways that reject fields they do not support.

## Highlights

- GPT Image now offers PNG, JPEG and WebP as explicit output choices. Models with GIF support also offer animated GIF.

## Product Updates

- Add image size, quality or background in Advanced Parameters when needed. If your provider requires a size, set it there before testing the connection.

## Fixes

- Text-to-image and image editing requests no longer force a PNG output format. Requests without streaming configured leave the streaming field unset. [#372](https://github.com/linshenkx/prompt-optimizer/issues/372)

## Breaking Changes / Upgrade Notes

- Previously saved image parameters still apply. Clear a setting to use the provider's default.

## Developer Notes

- Regression tests cover requests that omit optional settings and requests that explicitly select an output format.
