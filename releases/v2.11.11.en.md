# Prompt Optimizer v2.11.11

## Summary
- Corrects model selection for prompt analysis, result evaluation, and variable generation: an explicit evaluation model takes priority, followed by the global optimization model, the caller's fallback model, and the first enabled model.
- Improves reliability when models are deleted or disabled, lists are refreshed, and settings are saved, preventing stale requests from overwriting current state or using unavailable models.
- Includes persisted evaluation, image-recognition, and other known UI settings in backup and restore.
- Includes oversized-image preparation and first-time setup documentation improvements made since the previous release.

## Highlights
- Clear the evaluation model setting to restore automatic selection. The UI explains the default order and warns about deleted or disabled function models.
- Earlier evaluation responses no longer interfere with restarted evaluations, and rapid function-model changes are saved in user-action order.
- Image uploads are prepared for compatibility. Material resizing requires confirmation, and cancelling preparation leaves the existing input unchanged.

## Product Updates
### Desktop
- Receive the shared model-selection, evaluation, and backup fixes.
- Fix repeated quit-time storage saves preventing the desktop process from exiting normally.
- Preserve compatible JPEG inputs and their format while preparing oversized model inputs; PNG conversion uses the PNG output path.

### Web
- Improve image upload preparation and feedback in Text-to-Image, Image-to-Image, and Multi-Image workspaces.
- Simplify bilingual first-time model setup, workspace selection, and connection troubleshooting guides, with screenshots from the application.

### Core/Infra
- Allow function-model settings to be restored from backups and export persisted known UI settings even when they have not been read during the current session.
- Expand regression coverage for stale requests, model availability, and consecutive settings changes, and replace an obsolete model reference in the migration test fixture.

## Fixes
- Fix Basic-mode evaluations preferring the test model over the documented global optimization model, and align related evaluation entry points.
- Skip deleted or disabled evaluation models. Image recognition continues to require an explicitly configured, enabled model.
- Prevent earlier streamed text, results, and errors from overwriting an evaluation that has been cleared and restarted.
- Prevent obsolete model-list responses and refresh failures from overwriting newer state. Function-model callers wait for the latest availability read to finish.
- Notify workspaces after the last text model is deleted, and clear invalid selections after a successful empty-list read.
- Distinguish unloaded, failed, and successfully empty image-model lists so read failures do not clear saved test-column choices.
- Save and reload function-model preferences in operation order, preserving previous settings and displaying an error if a save fails.
- Restore evaluation and image-recognition settings from backups, including persisted known UI settings that have not been read after a restart.

## Breaking Changes / Upgrade Notes
- No manual user-data migration is required. Existing custom models and parameter settings are preserved.
- Without an explicit evaluation model, the global optimization model now takes priority. Select a model under Function Models to keep evaluation pinned to it.
- Disabled or deleted function-model preferences remain saved so re-enabling a model can restore the choice. Image recognition requires enabling that model or selecting another available model.
- Development and builds continue to require Node.js 24.

## Developer Notes
- The release range is `v2.11.10..HEAD`, with 18 content commits before the release metadata commit.
- Regression coverage includes evaluation priority, unavailable-model fallback, asynchronous read ordering, consecutive saves, stale evaluation responses, and backup restoration.
- Image upload and documentation improvements include changes already merged into the main release branch after v2.11.10 was packaged.
