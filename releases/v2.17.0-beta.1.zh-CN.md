# Prompt Optimizer v2.17.0-beta.1

## 概括

本预览版将桌面端结构化数据存储升级为本地 SQLite（WAL 模式）：首次启动时自动将原 `prompt-optimizer-data.json` 原子迁移到 `prompt-optimizer-data.sqlite`，同时原样保留旧版 JSON 文件作为升级前快照。本次同时强化了桌面端退出清理与启动异常提示，并修复了历史记录、模板、偏好设置及 IndexedDB 并发更新中的边界问题。

## 亮点

- **原子化的 SQLite 桌面存储**：用基于内置 `node:sqlite` 的 WAL 短事务替代原有整文件防抖写盘机制，完整保留模型配置、图像模型参数、模板、历史迭代链、上下文、收藏、偏好设置、变量及工作区草稿。
- **不改动历史 JSON 快照**：首次启动在单一事务内将 `prompt-optimizer-data.json`（或已有 `.backup`）迁移并校验写入 `prompt-optimizer-data.sqlite`，不会删除、覆盖或改写原有旧文件。
- **更稳妥的启动与退出保护**：在存储或服务启动失败时弹出清晰的故障引导（区分不支持 WAL 的目录、存储初始化失败与服务初始化失败，支持一键打开数据目录），并在应用退出期间串行守护未完成的 SQLite 关闭流程。
- **跨存储并发一致性修复**：历史链追加与导入、模板保存/删除、偏好清空以及浏览器 IndexedDB 队列写入均保持并发安全、根记录完整且领域错误不被掩盖。

## 产品更新

### Desktop

- 通过 `@prompt-optimizer/core/node` 将桌面端结构化存储从 `FileStorageProvider`（`prompt-optimizer-data.json`）切换为 `SQLiteStorageProvider`（`prompt-optimizer-data.sqlite`，WAL 模式）。
- 首次启动自动执行一次性原子迁移，原 `prompt-optimizer-data.json` 与已有 `.backup` 文件保持只读且原样保留在目录中。
- 在 `will-quit` 阶段串行阻塞重复退出直到 SQLite 关闭完成；致命启动失败时安全关闭存储并立即退出；自动更新出错时恢复退出前保存状态。
- 新增多语言（简体中文、繁体中文、英文）启动错误对话框，明确区分 WAL 目录不支持、存储失败与服务启动失败，并在无法打开目录时提示具体错误原因。

### Web

- 本次没有面向用户的 Web 端界面或交互变更；底层共享的浏览器端 `DexieStorageProvider` 优化了 `updateData` 并发队列与领域异常透传。

### Extension

- 本次没有扩展端特有的功能变化，构建产物已验证完全隔离 Node SQLite 模块。

### Core/Infra

- 提供独立的 Node 专用子入口 `@prompt-optimizer/core/node`（导出 `SQLiteStorageProvider`、`openDesktopStorage`、`openExistingDesktopStorage`、`openExistingDesktopStorageForWriting`、`exportDesktopStorageAsLegacyJSON`），与浏览器主入口物理隔离。
- 将 `HistoryManager`（`deleteRecord`、`deleteChain`、`addIteration`）、`TemplateManager` 写删以及 `PreferenceService.clear()`（新增原子 `deleteByPrefix`）统一切换为单事务原语。
- 新增 `trimRecordsPreservingRoots` 统一保护新增、迭代及导入时的 50 条截断逻辑，确保保留的每条链都留存版本 1 根记录，并自动重连被淘汰中间版本的 `previousId` 祖先链路。
- 在 SQLite 原始键值写入与旧版 JSON 迁移时将孤立 UTF-16 代理项规范化为 `U+FFFD`（遇到旧键冲突时回滚拒绝），同时保持正常 JSON 序列化字段完整无损。

## 修复

- 修复 `HistoryManager.addIteration` 在多连接并发或链被删除时的竞态分叉问题，并确保返回值在 50 条截断下与存储读取结果一致。
- 修复超出 50 条记录时多条活跃链互相挤掉根记录、`getIterationChain` 在被淘汰中间节点处断链，以及最新优先导入 51 条记录丢失根记录的问题。
- 修复 `PreferenceService.clear()` 清理跨连接写入及未缓存键时的并发撕裂隐患，支持前缀原子清除。
- 修复 `DexieStorageProvider.updateData` 在修改器抛出 `RecordNotFoundError` 等业务异常时误触发重试/降级包装为 `StorageError` 的问题，并修复同键并发队列前序失败波及后续合法写入的问题。
- 修复 `packages/desktop/main.js` 退出辅助逻辑位置对核心桌面服务桥接测试切片的影响，并将底层文件标识的 `birthtimeNs` 检查限定在 `win32` 与 `darwin` 平台。

## 破坏性变更 / 升级说明

- 本版本为预览版（`v2.17.0-beta.1`），用于体验与验证桌面端共享 SQLite 存储平滑升级；升级前建议先通过应用内导出或备份功能留存重要数据。
- 升级后桌面端新增与修改数据将保存至数据目录下的 `prompt-optimizer-data.sqlite`；原有的 `prompt-optimizer-data.json` 保留为升级前历史快照，后续不会再同步更新，也不会在后续启动时重读。
- SQLite WAL 模式要求桌面端数据目录位于支持文件锁的本地磁盘卷；若数据目录位于不支持文件锁的特殊网络盘/虚拟磁盘，应用会暂停启动并提示迁移数据目录，不会修改原文件。
- 桌面端与浏览器端的图片资产 IndexedDB（`PromptOptimizerImageDB`、`PromptOptimizerFavoriteImageDB`）本次结构不变。
- 扩展数字版本为 `2.17.0`，显示版本为 `2.17.0-beta.1`；扩展 ZIP 供手动安装，本预览版不提交商店审核更新。
- Docker 镜像仅推送 `2.17.0-beta.1` 标签，不会覆盖稳定版 `latest` 标签，也不影响正式版桌面更新通道。
