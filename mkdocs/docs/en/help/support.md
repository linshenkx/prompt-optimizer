# Technical Support

For setup questions, start with [Common Questions](common-questions.md), [Connection Issues](connection-issues.md), or [Troubleshooting](troubleshooting.md).

For a reproducible bug or documentation error, use the [project's GitHub issues](https://github.com/linshenkx/prompt-optimizer/issues). Include the app version (web, desktop, or extension), your operating system and browser, workspace, steps to reproduce, expected and actual behavior, and any visible error.

For model requests, include the provider, model name, and API URL if they help reproduce the issue. **Remove API keys and other secrets from screenshots, logs, and URLs before posting.**
