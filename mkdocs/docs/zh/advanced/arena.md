# 竞技场

竞技场把同一道题交给多个测试栏，方便并排查看不同模型、不同设置的实际输出。适合选择目标模型，或比较同一模型在不同参数下的表现。

![GPT-6.2 Astra、GPT-6.2 Sol 和 DeepSeek Flash 对同一道机械鲸鱼绘图题的输出](../assets/images/product/2026-11/arena-comparison.jpg)

*同一道题，三个模型各自生成 HTML/SVG 场景；各列保留模型配置的默认参数。*

## 开始一次比较

1. 在[模型管理](../basic/models.md)配置并启用可用的模型。
2. 打开顶部 **竞技场**，填写一条完整任务。
3. 为每个测试栏选择连接和模型；点击 **添加测试栏** 可增加结果列。
4. 如需比较参数，在模型下拉框中修改当前列设置。
5. 点击 **测试全部**，或只运行某一列的 **测试**。

也可以从 **测评题** 入口选择题目，或通过提示词库导入题面。输入、模型服务和额度仍由你自行准备。

## 一次比较一种变化

| 要比较什么 | 保持一致 | 可以变化 |
| --- | --- | --- |
| 不同模型 | 题面、参考图片及尽量一致的其他条件 | 每列模型 |
| 同一模型的不同设置 | 题面、输入、连接与模型 | 一个要研究的参数 |
| 同一设置的稳定性 | 题面、输入、模型与参数 | 重复运行的结果 |

先看是否完成任务、遵守约束和包含错误，再考虑风格与表达。耗时与成本以可用的运行记录和服务商计量为准。

## 每列独立的参数

在提供独立参数控件的版本中，收起的下拉框显示当前思考或参数摘要。默认继承模型配置；修改只影响当前列，不会改写其他列或共享连接。

模型可能提供思考档位、开关、预算或其他参数。只使用实际提供、且服务端支持的取值；不同提供商的同名档位不一定等价。详见[模型选择与参数](../basic/model-parameters.md)。

## 文本、图像与思考内容

- 文本模型直接回答题面；返回的 HTML 或 SVG 可在支持的预览中查看。
- 图像模型根据题面出图。需要参考图时，使用 **添加参考图片**，并选择支持相应输入的模型。
- 混合比较文本与图像时，先确认各列都能处理共同输入。
- 服务返回思考内容时，结果区会显示相应区域。部分服务不提供或只返回摘要，不能仅凭是否显示思考判断模型能力。

## 修改后继续运行

已有结果属于原来的运行。修改题面、模型或参数后，重新运行受影响的列，再做比较。会话会保留题面、列设置与输出；跨设备迁移前使用[数据管理](../basic/data.md)备份。

竞技场用于直接执行和比较。需要改写提示词、比较原始与优化版本，或应用评估建议时，选择[基础或上下文工作区](../user/choose-workspace.md)。
