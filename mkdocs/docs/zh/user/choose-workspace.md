# 选择工作区

第一次使用，先按[快速开始](quick-start.md)在 **用户提示词优化** 中跑通一个例子。之后根据你想完成的任务选工作区。

| 我想做什么 | 选择哪个工作区 | 还需要准备什么 |
| --- | --- | --- |
| 写邮件、改写一段话、生成摘要 | [用户提示词工作区](../basic/user-optimization.md) | 一条任务要求 |
| 设定客服助手的角色、长期规则和输出边界 | [系统提示词工作区](../basic/system-optimization.md) | 一段用于验证规则的用户问题 |
| 反复替换主题、产品名、语气等内容 | [变量工作区](../advanced/variables.md) | 带 `{{变量}}` 的模板和测试值 |
| 在多轮对话中修改某条消息 | [多消息工作区](../advanced/context.md) | 完整会话，选定要优化的消息 |
| 只根据文字生成图片 | [文生图工作区](../image/text2image-workspace.md) | 文本模型和图像模型 |
| 基于一张输入图片继续生成 | [图生图工作区](../image/image2image-workspace.md) | 输入图、文本模型和图像模型 |
| 综合多张图片生成新图片 | [多图生图工作区](../image/multiimage-workspace.md) | 至少两张输入图及支持多图的图像模型 |

**用户提示词与系统提示词怎么区分？** “帮我写一封邮件”是一件具体任务，放在用户提示词工作区；“你是客服助手，每次先确认订单信息，不编造退款政策”是希望长期遵守的规则，放在系统提示词工作区。

**什么时候用变量？** 当你会反复替换同一结构里的内容时，用 `{{主题}}`、`{{语气}}` 等变量把提示词做成模板。只运行一次的任务，先用用户提示词工作区。

**什么时候用多消息？** 当输出依赖前面几轮对话，而且你要调整其中一条 `system` 或 `user` 消息时，再使用多消息工作区。

进入工作区后仍要选择相应模型。文本工作区至少需要一个文本模型；图像工作区通常同时需要文本模型和图像模型。先看[模型管理](../basic/models.md#model-types)，遇到按钮不可用时看[故障排除](../help/troubleshooting.md)。
