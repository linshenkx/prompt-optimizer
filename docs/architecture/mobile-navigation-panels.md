# 移动端导航面板

2026-10-22：仅调整 compact 呈现，桌面 AppCoreNav 的布局和点击行为保持不变。

- 功能菜单使用内容自适应的底部面板，收藏、历史、功能提示词、模型、变量、数据两列三行；主题与语言紧凑同行，帮助与关于默认折叠。
- 模式选择一次展示基础的系统/用户、上下文的变量/多消息、图像的文生图/图生图/多图生图。分类标题仅说明分组；点击具体模式关闭面板、释放覆盖层历史记录，再进入对应既有路由。选择当前模式只关闭面板。
- 收藏页选择原工作区对应模式仍应实际返回该工作区。管理页继续复用现有业务组件，移动端全屏显示；模板编辑页的类型和帮助按钮与标题同行。
- 新增 AdaptiveModal 的 sheet 呈现只在 compact 时生效，其他默认呈现保持不变。面板在短屏内限制高度并允许内容滚动，不能遮断帮助入口；七个模式和六个功能入口在目标尺寸中均可直接看到。

验证：PKX110 真机 360×669 网页视口；模式导航及七模式原有双列结果恢复；模型编辑保存、模板和变量编辑取消、历史/数据/收藏往返及真实软键盘按钮可达。浏览器补验 393×852、412×915、430×932 和 852×393，并核对 1440×900 桌面导航、工具入口及工作区矩形与修改前一致。13 项导航/覆盖层测试、类型检查和 Web 打包通过。

本轮不重新运行模型，不执行远程备份授权或覆盖式导入/还原。

## 业务组件适配边界

本阶段完成的是移动导航、弹窗容器、滚动与键盘避让，以及部分操作的可达性验证。上述模型编辑保存、列表往返等检查，不代表模型、模板、历史、收藏、变量和数据管理已经完成独立的手机交互设计。它们仍大量沿用桌面业务组件的列表、卡片、表单及操作组织，完整移动端体验尚未完成。

后续应逐个设计业务组件的移动呈现并在真机验证，保留既有业务逻辑与桌面布局；本页不将这些待办写成已通过，也不新增本轮未执行的验收结论。
