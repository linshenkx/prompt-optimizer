# 移动端同屏工作区（2026-10-21）

本阶段实现依据用户选中的第二张效果图：保留底部“优化 / 测试”和回答 A/B/C/D 两层切换，其余信息通过同屏排布、下拉和局部折叠呈现。本阶段设计取代上一阶段“原始提示词 / 优化工作区”和“测试配置 / 测试结果”内部分页。

## 优化区

原始输入与当前工作稿上下同屏。原始输入可局部折叠，模型、模板和优化按钮紧凑排列。当前稿继续使用 PromptPanel/OutputDisplay，保存版本改用下拉，渲染/文本/对照进入显示菜单。切换版本保留未保存修改确认；继续优化保留既有表单。

## 测试区

输入/变量/参考图、全部已启用组的来源与模型、运行操作、回答选择和正文位于同一滚动区域。2/3/4 组数量进入“更多设置”；A/B/C/D 只选择回答，不再隐藏其他组配置。每组来源按钮保留完整预览和前往编辑。

回答前默认显示三行提示词参考，可展开全文；长回答阅读时，组选择和简短参考保持可见，展开参考则随内容滚动。每组分别记住滚动和展开状态，底部导航不覆盖最后一行。

## 请求上下文

新测试在发出请求时记录实际提示词。基础系统包含 system/user，变量和多消息采用已经替换变量的文本/会话，图像模式采用实际生成请求的 prompt。结果与该快照绑定，随后编辑不改写旧快照。四个文本 session 新增可选 requestPrompt 并保留持久化；图像使用结果 metadata.prompt。旧结果没有快照时明确显示“当前提示词参考”，不推断其历史输入。

## 覆盖与复用

覆盖 basic/system、basic/user、pro/multi、pro/variable、image/text2image、image/image2image、image/multiimage。共享 OptimizeWorkspaceLayout、TestWorkspaceLayout、VariantTestWorkspaceLayout、TestPromptReference 和 useCompactWorkspace；模式级仍调用现有编辑器、服务、状态和结果组件。桌面并排、管理弹窗和原有能力保留，移动端不新增 AI 评估。
