## 已完成的真实文本流程

在正式应用路由 `/#/basic/user`，430 × 932 移动尺寸下输入蓝牙耳机售后回复要求，调用免费 DeepSeek 优化到 V1，再将 A/B 两组显式选择为同一个免费模型，点击“测试全部”。

- 优化和 A/B 三次业务请求成功，Magpie 对应日志记录最终 HTTP 200；A/B 两次耗时约 11.2 秒、17.3 秒。
- A 为原始提示词，返回客服正文及额外说明；B 为优化稿，返回客服正文。此处仅报告实际差异，不据单个案例宣称模型质量提升或所有约束均满足。
- 切换到 B 后展开“本次实际提示词”，滚动可读到提示词末行与回答末行，未被底部区域切换遮挡。
- 在 `/#/image/text2image`，免费 DeepSeek 将国风少女/莲花灯的原始描述优化为 V1。
- 免费上游间歇返回 HTTP 503 `Endpoint is unavailable`。基础优化经 SDK 重试成功；图像提示词第一次业务请求失败，手动重试后成功。未偷偷切换为付费文本模型。

## 其他模式的实际布局改动

| 模式 | 移动端适配 |
| --- | --- |
| 基础系统 / 用户 | 原文与工作稿同页；紧凑模型和模板行；底部优化/测试；A/B 配置与结果同页。 |
| 上下文变量 | 变量名、值、操作同排；面板可折叠；零变量时保留添加入口。 |
| 上下文多消息 | 消息编辑器可折叠；紧凑角色和操作；测试提示词保留多角色完整上下文。 |
| 文生图 | 灵感、复刻、风格学习合并为辅助菜单；缩小编辑器间距；图片结果适配手机可用高度。 |
| 图生图 | 参考图预览与操作压缩排列；复用上传、预览、工作稿和结果组件。 |
| 多图生图 | 横向参考图缩略图和前移/后移操作；保留图片顺序。 |

这些改动限于 compact/mobile 分支或样式，桌面保留原有布局。各模式的布局和模拟交互已有证据；真实模型覆盖需按本报告逐项记录，不能推定七个模式全部真实调用通过。
