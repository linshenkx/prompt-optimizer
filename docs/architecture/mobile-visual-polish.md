# 基础模式移动端视觉打磨 · 2026-10-20

范围：保留已确认的“优化 / 测试”主区域，以及各自的内部视图。复用既有输入、模型选择、版本、输出和业务服务，只调整移动布局、视觉与操作层级。

## 四个视图

| 视图 | 原问题 | 本轮调整 |
| --- | --- | --- |
| 原始提示词 | 卡片包输入框、重复边框；选择器像桌面表单 | 统一手机字体回退与圆角，移除外层卡片边框；原文占据剩余高度，模型与模板并排，主操作统一高度 |
| 优化工作区 | 三层按钮同时抢注意力；选中的文本模式看起来不可用 | 页面切换采用下划线，工具切换采用轻量选中态；文字对照、复制、全屏仍使用原组件 |
| 测试配置 | 运行按钮在配置之前，版本和模型纵向占据大量空间 | 版本和模型并排；运行按钮排在配置之后，DOM 顺序与视觉、键盘顺序一致 |
| 测试结果 | A/B、运行、阅读工具都像同等级大按钮 | 分组使用紧凑分段控件，运行保留主操作；来源与模型用摘要展示，正文去掉嵌套卡片，阅读工具栏继续吸顶 |

底部主导航使用图标与短标签，内层页面使用下划线，A/B 组使用分段控件。三个层级有不同外观。输入文字仍保持 16px，未靠缩小正文腾空间。

样式使用已有主题，移动主导航强调色取当前主题的 primaryColor。深色主题补充运行按钮、组数和分组选中态的文字对比度。字体栈包含 PingFang SC、Microsoft YaHei UI / YaHei、Noto Sans CJK SC；浏览器实际字体检查确认中文控件使用 Microsoft YaHei UI。

## 验证

- 393×720：四个视图留存同状态前后截图。配置示例中输入、版本、模型与运行按钮同屏显示。
- 360×640：系统模式示例配置无需滚动即可看到完整运行按钮；无横向溢出。四组 A/B/C/D 与运行操作同屏。
- 模拟运行通过新的配置入口进入结果；约 2400 字长回答可滚到末行。A→B→A、配置→结果保留阅读位置。
- 用户模式深色视图检查，原文差异对照可切换；深色组数文字和分组选中态补充对比度。
- 实际 Web 页面通过 18181 的 393px iframe 检查：真实导航、选择器和原文视图显示正常，无横向溢出。另检查 360×640 系统模式：配置容器 clientHeight / scrollHeight 均为 444，运行按钮底部在容器可见范围内。
- 真实应用与示例的样式注入顺序不同；最终将短屏间距规则放入布局组件自身的 scoped 样式，避免被组件的默认 12px 间距覆盖。
- 1280×720：桌面同时显示原文、优化工作区与两列测试结果，没有移动内部切换条。
- UI typecheck、受影响 Vue 文件 ESLint、git diff --check 通过。输出与布局相关既有回归 11 项通过。

模型运行使用独立内存示例与模拟服务，没有调用用户模型。尺寸模拟不等于手机实机软键盘、浏览器工具栏及手指触控验收。
