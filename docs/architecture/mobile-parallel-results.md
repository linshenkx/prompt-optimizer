# 移动端测试结果同屏对比

2026-10-21。用户要求测试结果并行展示以便比较，替代移动端 A/B 标签切换。只调整移动端，保留底部优化 / 测试两个区域。

## 实现

- 七个工作区的移动端结果固定两列。2 组左右对比，3–4 组按两列换行；各结果沿用原有 OutputDisplay / AppPreviewImage。
- 每个结果有 A/B/C/D 标识、来源、单组测试按钮。单组按钮调用原来的 runVariant；顶部保留测试全部。
- 每张卡片显示一行提示词摘要。点击打开现有 TestSourcePreview，优先展示该结果保存的 requestPrompt / metadata.prompt；没有请求记录时明确标记当前提示词参考。
- 长文本不裁掉末尾，仍由测试区整体滚动，保留全文放大、渲染 / 原文、收藏和复制。窄列复制入口使用原复制动作菜单。
- 图片等比展示，生成详情默认折叠、展开后换行，仍可放大和下载。
- 桌面分栏算法、工具栏、生成详情常显和原测试执行逻辑不变。不修改模型、会话内容或已有结果。
