# 实机截图审查与免配置生图接入

日期：2026-10-21。本轮 UI 工作是分析与复现，未调整移动端或桌面端布局；实际实现范围是当前开发预览的生图自动配置。

## 尺寸与证据

用户提供 5 张 Android Chrome 实机截图，原始文件均为 1080×2344。扣除状态栏、地址栏和系统手势栏后，按约 3 倍像素估算网页可视区为 360×668 CSS px。浏览器按此尺寸复现，输入框、模型行、工作区标题及底栏位置与截图基本对齐；精确 CSS viewport、DPR、系统字体设置仍需手机运行时数据确认。

浏览器原先使用的 430×932 明显宽且高：比此估算宽约 19%、高约 40%。不能仅用更大模拟尺寸判断实机体验合格。今后本轮项目的基准使用 360×668，补充 393×852 和 430×932；软键盘、地址栏伸缩、实际触摸和读屏仍需实机验证。

截图均位于 `.codex-run/phone-real-size-20261021/`。Ego xyz Profile 8 的独立 TaskSpace 6 在 Page.captureScreenshot 超时，随后使用独立内置浏览器页面，通过实际局域网 origin 复现。

## 按使用步骤分析

1. **原文输入（可操作，空状态较弱）**：对应 user-01-empty.jpg / 01-system-empty.png。顶栏及底部优化/测试清晰；短输入也占约 90px，空工作区显示工具条和大片空白。建议初始只保留紧凑输入和行动提示，无内容时弱化工具栏。
2. **生成中（反馈存在，布局不稳定）**：对应 user-03-optimizing.jpg / user-04-testing.jpg / 03-system-testing.png。按钮文字变长挤压模型和模板；按钮、卡片与底栏重复显示运行状态。流式正文与工具栏间出现较大空白，截图无法单独确认其具体原因。建议固定主按钮尺寸和内容起点，减少重复反馈，保留标签与正文对比度。
3. **阅读优化稿（主内容出现过晚）**：对应 user-02-optimized.jpg / 02-system-optimized.png。实际复测 h1 在 y=456px，字号 24px、底 margin 24px，第一条正文已接近底栏。建议移动端压缩原文区、合并工作区工具行，使用适于编辑的标题/段落间距；保留现有原文展开和全文阅读能力。不宜把整页字体统一缩小。
4. **配置测试（字段可用，信息重复）**：对应 user-04-testing.jpg。上方 A/B 配置中已有来源和模型，下方又重复 A/B 来源、提示词摘要和整排工具条。建议运行后配置可收起为摘要，保留明确编辑入口；提示词查看与必要结果操作集中到每列紧凑表头。
5. **比较结果（方向正确，正文可视空间不足）**：对应 user-05-results.jpg / 04-system-results.png。并排比较和提示词快照有价值。360×668 复测正文首段 y=470.8px，底栏 top=605px，首屏只有约 134px 可看回答。两列各宽 158px，正文约 140px，故不应再一味缩字。建议压缩配置与表头、保留并排预览和单列全文放大，争取首屏正文空间提高到约 250–300px。

可见的可访问性风险：运行时多个控件整体变淡，状态与不可用原因不够清楚；双列密集图标易误触。截图不能证明实际触摸命中、焦点/读屏语义或键盘遮挡已通过。

当前文本预设可调用，但本轮例子中极短原文被扩写为很长的角色/规则稿，进一步放大布局问题；本轮未修改模板，也不据单例宣称优化质量变好。

## 预览生图接入

- 现有 Mobile Preview 来自此工作树 `.env.local` 的自定义文本配置，实际是远程 Qwen/Qwen3-32B，不是在手机上运行的模型。
- 专用 `vite.workspace-preview.config.ts` 开发预览自动提供 `Mobile Preview · GPT Image`，使用现有 OpenAI 图像适配器、Magpie `codex/gpt-image-2`，预设 quality=low 供快速测试。文生图、图生图、多图生图能力沿用适配器；不改正常 Web / Electron 的出厂模型配置。
- 初始化只补充缺失配置；保留已有同 ID 的用户编辑或显式禁用。Base URL 按 window.location.origin 生成，手机不用填电脑 IP、密钥或模型 ID。
- 初次真实调用被 Magpie 的来源保护拒绝。按官方要求，在 Magpie 保留原设置并追加当时局域网预览的精确网页来源（端口 18181）；设置原文件已备份至其原目录。
- 新增专用网关密钥 `Prompt Optimizer Mobile Preview`，仅允许 `codex/gpt-image-2`。密钥仅保存在本地非 VITE_ 环境变量，由电脑端图片代理注入。未开放 Magpie 的 LAN 监听或管理端点，未改其他供应商/账户。
- 浏览器可下载的 env 模块和预览模型模块已检查不含网关密钥；临时密钥输出文件已清理。
