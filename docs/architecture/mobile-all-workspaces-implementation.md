# 其余工作区移动端实现与验证

日期：2026-10-20；最终检查完成于 2026-10-21 凌晨。

状态：上下文及图像五个工作区已接入两区布局，延续基础模式的移动端设计。可在本地默认端口体验；尚未提交、推送或发布。本文的浏览器流程使用隔离模拟服务，不代表新增五个模式的真实模型调用或手机实机验收。

## 本轮范围

| 工作区 | 路由 | 保留的业务能力 |
| --- | --- | --- |
| 上下文多消息 | `/#/pro/multi` | 多角色消息、选中消息优化、应用回会话、上下文与工具编辑、整段对话来源查看和测试 |
| 上下文变量 | `/#/pro/variable` | 提示词变量填写、预览、优化、各组测试 |
| 文生图 | `/#/image/text2image` | 文本优化模型、优化模板、图像模型、提示词来源、生成与结果操作 |
| 图生图 | `/#/image/image2image` | 参考图上传与预览、提示词优化、携带参考图测试 |
| 多图生图 | `/#/image/multiimage` | 多参考图、顺序调整、提示词优化、携带多图测试 |

统一入口：`http://127.0.0.1:18181/`。通过顶部原有模式切换进入；无需另外打开原型。

## 交互与复用

- 底部“优化 / 测试”自由切换。优化内“原始提示词 / 优化工作区”，测试内“测试配置 / 测试结果”。
- 原编辑器、提示词版本、差异显示、测试输出、session store 和服务接口继续复用。切换通过显隐保留组件实例，不生成第二份业务状态。
- 七个模式分别保留区域、内部视图、选中测试组和阅读位置。有效请求开始时进入输出；用户随后离开，后续批次和完成事件不抢走当前视图。
- 测试配置包含输入、2/3/4 组、当前组的来源与模型。结果显示一组，固定分组与运行入口，正文单独滚动。
- 来源摘要打开完整提示词；多消息模式显示实际完整会话。明确点击“前往编辑”才切回对应编辑区域。
- 移动布局隐藏 AI 评估入口；桌面并排布局及原有评估保留。
- 应用历史/收藏内容时，扩展模式重置移动视图，避免新内容被留在隐藏区域。

共享实现为 `useCompactWorkspace`、`VariantTestWorkspaceLayout`，组合已有 `OptimizeWorkspaceLayout`、`TestWorkspaceLayout` 和 `WorkspaceRegionSwitch`。模式级代码只提供原组件、当前组摘要与现有操作回调。

## 本轮细节修正

- 变量填写：桌面固定宽度的变量名和操作区曾把窄屏输入框挤到零宽；手机改为名称与操作在上、输入全宽在下。
- 上下文消息：角色和操作一行，正文独占下一行。长内容仍用原编辑器。
- 参考图：横向缩略图列表，多图增加前移/后移按钮；桌面拖动排序保留。
- 图像结果：先图片，再下载/复制，再模型返回的文字，下载入口不再被长文字推到末尾。
- 上下文、工具、提示词预览、图像上传及图像模型编辑接入 `AdaptiveModal`。长表单在窄屏全屏，短变量输入仍使用紧凑对话框。
- 本地预览关闭符号链接路径保留并去重 Vue，修复预览中 CodeMirror 状态模块重复导致真实上下文编辑器打不开的问题。
