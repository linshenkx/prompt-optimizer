## 架构与兼容性

- 移动布局以可用容器空间为依据，复用业务状态和服务；保留宽屏桌面的分栏、评估和操作方式。这里不承诺所有设备都已逐一验收。
- 共享编排使用窄接口，模式特有的版本解析、模型选择、请求构造和结果处理仍由各工作区负责。参见[编排整理](../architecture/workspace-orchestration-refactor.md)。
- 数据可靠性是共享层改进，会影响 Web 的保存保护；不能把“桌面界面保持不变”表述成“所有底层代码完全没动”。无原子写入能力的提供者保留原兼容路径。参见[持久化边界](../architecture/workspace-persistence-safety.md)。
- PWA 只在 Web 生产环境注册。Electron、扩展和开发 HMR 不接入 Worker；本轮没有桌面主进程或扩展专属源码变更。
- 正式构建不带私有 Magpie 配置、测试密钥、QA 浏览器状态或手机导出包。本地带模型预览与公开发布包是不同用途。

## 必须保留的升级说明

1. PWA 需要可信 HTTPS / localhost；局域网 HTTP 在线可用，但不能据此宣称支持安装。
2. `ACCESS_PASSWORD` 的 Basic Auth 仍保护页面，提供在线使用，不安装离线壳。反向代理不能把运行配置或鉴权响应改成公开缓存。
3. 离线可处理已保存的本地工作，模型执行仍需联网。不同协议、域名或端口之间的数据需要导出/导入，不会自动迁移。
4. 有运行任务、未保存表单、真实写入冲突或同作用域其他窗口时，更新可能被阻止；先保留草稿并按提示处理。
5. Android 已有真机证据；iOS Safari 仅有安装指引，未做实机验收。不能写“所有移动平台完整验收”。
6. v2.11.13 记录的 Electron 内置 Node 与 Vercel 托管运行时补丁边界不属于本轮修复，本次没有重新核验上游运行时。下一次公开发布前需复核并保留仍成立的说明，不能宣称本轮已消除此类风险。
