# 数据管理改版验证记录

日期：2026-10-28。基于 develop 的 `f5a9a677`；仅本地实施与提交，不含推送或发布。

## 实现范围

- 桌面和移动端统一为“备份 / 恢复 / 存储设置”。备份共用目的地和内容选择；配置、教程、统计及维护工具移入设置。
- 本地文件、云端记录、导入码分别保留输入，最终恢复统一经过确认区。导入码只读取指定快照，不自动恢复，也不回退到其他快照。
- 一个控制器管理连接、请求版本、操作互斥及会话恢复。切换页签不重新创建控制器；配置变更使旧目标失效。保留已有凭据持久化和只读连接规则。
- 云记录按时间排序，支持本地搜索，每页至多 20 条；只展开所选记录。统计延迟到进入设置后读取。
- 历史 JSON 预览复用核心 `validateImportData`；连续选择文件采用最新文件，过时读取结果不能覆盖当前目标。文件选择不触发上传。
- 简体中文、繁体中文、英文同步更新。未修改备份格式、存储工具、远程目录或版本号。
