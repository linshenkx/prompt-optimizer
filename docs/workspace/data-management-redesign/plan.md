# 数据管理页面改版方案

状态：已完成本地实施与专项验证，见 [验证记录](validation.md)。日期：2026-10-28。

## 1. 目标与范围

保留“数据管理”入口和现有自适应窗口，将页面按用户任务整理为“备份 / 恢复 / 存储设置”。用户先选择要做什么，再看到相关选项。

本次覆盖桌面 Web、移动端、桌面应用及扩展共用的数据管理界面。复用当前组件库、图标、主题和响应式规范，不增加独立路由。

已完成的凭据持久化、只读连接、列表状态和过时响应保护继续保留。本次不增加后端、定时备份、自动同步、令牌续期、自动清理或恢复前自动备份；不修改备份格式、导入码格式、云端目录和已有数据，不做数据迁移。

## 2. 页面结构与默认行为

| 页签 | 主任务 | 主要内容 |
| --- | --- | --- |
| 备份 | 保存当前数据 | 保存位置、备份内容、执行按钮、当前结果 |
| 恢复 | 从已有备份找回数据 | 恢复来源、选择备份、确认范围、执行与结果 |
| 存储设置 | 管理云连接与存储空间 | 连接配置、占用统计、云图片清理、桌面存储目录工具 |

- 普通打开默认进入“备份”。从导入码链接进入时，打开“恢复 → 导入码”，预填内容，不自动执行恢复。
- 桌面与移动端使用相同的三个页签和名称。移动端取消当前“导出 / 导入 / 远程 / 存储”的第二套任务入口，页签在窄屏仍可直接看见，内容单列展示。
- 页签切换保留当前文件、配置草稿、范围选择、所选备份和操作进度；不重建控制器，不把界面切换当作重新执行任务。
- 需要连接配置时跳转至“存储设置”，保留原任务。保存并连接成功后显示“返回备份”或“返回恢复”，由用户返回后继续操作，不自动备份或恢复。
- 当前配置完整的云服务可作为首次进入备份时的默认位置；Google 还需有可用的本地授权。否则默认“本地文件”。默认值只在进入时确定，连接失败不会自动切换目的地，也不会尝试其他服务。
- 本轮不增加跨会话的页签偏好、备份历史数据库或多账号连接管理。云服务继续复用现有配置格式及每种服务的已保存配置。

## 3. 备份页

操作顺序：选择保存位置 → 确认备份内容 → 创建备份 → 查看结果。

### 保存位置

- 同一个位置选择器提供“本地文件、Google Drive、Cloudflare R2、S3/MinIO、WebDAV”。
- 选择本地文件时，仅展示下载备份所需内容。
- 选择云服务时，展示服务名称、已有连接状态及“管理连接”入口。
- 未配置、未授权或授权失效时，在原位置给出“设置连接”或“授权 / 重新授权”动作；不展示整套配置表单，不自动打开授权窗口。
- 连接成功仅说明列表可读取；实际写入权限仍在创建备份时验证，不显示“全部权限正常”等未经验证的结论。

### 备份内容

- 默认包含当前支持的全部备份内容。
- 默认展示简短摘要，“调整备份内容”展开后提供应用数据、应用相关图片、收藏夹（含收藏图片）。依赖关系和实际导出规则沿用现有实现。
- 本地与云端共用这一组选项。当前代码已经共用范围状态，本次让界面明确体现这一关系。
- 不把 Google 授权令牌加入普通备份或快照。其他已有格式与凭据边界保持不变。

### 执行与结果

- 本地按钮用“下载备份文件”，云端按钮用“备份到 Google Drive”等明确目的地的文案。
- 每个状态只有一个主要执行按钮；运行中显示当前阶段并阻止重复启动。
- 本地导出成功显示“已生成并开始下载备份文件”，不声称已经确认文件落盘；云端写入完成后才显示备份成功，并给出“查看这份备份”。
- 图片缺失等部分成功情况保留现有提示，不合并成完全成功。
- “查看这份备份”切换到恢复页并定位刚生成的快照，复用已知结果，不重新创建备份。

## 4. 恢复页

操作顺序：选择来源 → 读取 / 选择备份 → 查看恢复内容和影响 → 确认恢复。

来源为“本地文件 / 云端备份 / 导入码”，一次只展示一种来源的输入区域。

### 本地文件

- 保留拖放和文件选择，兼容现有 ZIP 与历史 JSON。
- 选中文件后读取现有预览信息，展示文件名及可恢复内容，再展示恢复范围与必要提示。
- 文件不可读或格式不支持时就地报错，不保留上一份文件的恢复目标。

### 云端备份

- 展示当前云服务摘要及服务切换入口；连接设置放在“存储设置”。
- 将当前备份下拉框替换为按时间从新到旧排列的记录列表，支持使用已有名称或日期在本地筛选。
- 每条记录优先显示时间、包含内容和已有图片数量；缺失资源明确提示。历史备份缺少元数据时显示可得信息，不补造内容。
- 不将清单文件大小当作整个备份大小；本轮不增加扫描全部远程文件来计算总大小的请求。
- 加载完成后不自动进入恢复确认。用户选定记录后，显示该备份的详情和恢复范围。
- 记录中的“生成导入码 / 二维码”归入次要操作。Google 不提供这一动作；相关限制放在说明中，不常驻展示不可用按钮。
- 列表较多时采用有界滚动和现有列表能力，避免一次渲染大量复杂详情；只展开当前选中的备份。

### 导入码

- 放入独立来源，保留输入框及现有格式校验。
- 主动作改为“读取备份”：校验完整导入码 → 使用其中的连接配置 → 只读加载 → 精确定位指定快照 → 展示恢复确认区。
- 指定快照不存在时明确报错，不回退到最新或其他快照。
- 这是本次明确的交互变化：当前“导入并恢复”一步执行，改为“读取备份 → 确认恢复”。打开链接、粘贴、读取或切换页签都不触发恢复。
- 保留导入码携带 R2/S3/WebDAV 连接凭据的格式和相关提示；Google 授权仍不能借导入码迁移。
- 导入码加载期间拥有目标选择权，普通自动加载不能覆盖它的连接、指定快照或最终确认状态。

### 统一恢复确认区

- 仅在明确选定并读取了备份后出现，放在当前恢复页，不连续嵌套多个确认弹窗。
- 显示来源、备份时间或文件名、可恢复内容和本次选择；仅显示备份实际包含且支持恢复的项目。
- 仅当本次包含收藏夹时显示“已有同一条收藏时”的处理方式，沿用当前默认值和收藏身份规则；内容相同但身份不同的收藏不会因此被去重。
- 应用数据、会话草稿、测试结果等的覆盖或更新说明在此展示，准确沿用实际恢复语义，不宣称整个应用都会清空或整体回滚。
- 最终按钮为“确认恢复”。此动作完成必要确认后只执行一次；不在后续再添加内容重复的通用确认弹窗。
- 本地和云端使用共同的展示结构，底层仍调用各自现有恢复实现，保留预检查、图片完整性处理、工作区互斥、恢复后会话落盘及刷新规则。
- 成功、部分成功和失败分别呈现；失败保留可重试的信息，但不自动重试。

## 5. 存储设置页

### 云连接

- 放置服务选择、连接摘要、“编辑配置”及“保存并连接”；Google 展示“授权 / 重新授权”。
- 已连接时默认展示简洁摘要；首次未配置、用户编辑或需要修正配置时展开表单。
- 保留输入自动本地保存，但不随输入发起连接请求。“保存并连接”继续共用一次只读列表请求。
- 失败保留配置和具体错误；Google 401 提示重新授权，403 保留实际原因，网络错误不变成授权过期。
- 配置教程按服务放入可展开帮助，仅在用户需要时展示。

### 空间与维护

- 存储占用从首屏移到此页。首次进入时读取，保留手动刷新；显示估算值与实际值的区别，合并重复说明。
- “清理未引用图片”归入当前云连接的维护区域，明确作用对象，沿用先分析、展示影响、用户确认后执行的现有逻辑。
- 本地空间统计和云端图片清理明确区分，避免误以为清理会减少浏览器本地占用。
- 桌面应用保留数据目录、现有桌面备份占用和“打开目录”；Web 与扩展不展示这些桌面专属操作。
- 不新增本地清空、批量删除云备份或自动清理功能。

## 6. 状态、加载和并发约束

三个页签共享同一份连接状态、远程列表、配置版本和请求序号。UI 拆分不复制控制器或增加请求来源。

| 情况 | 页面行为 |
| --- | --- |
| 尚未读取 | “连接后读取备份”或“尚未加载”，不显示没有备份 |
| 正在读取 | 展示读取状态，合并当前连接的重复请求 |
| 成功且为空 | 明确“此位置暂无备份”，可引导前往备份页 |
| 首次读取失败 | 展示具体错误与重试 / 连接处理入口 |
| 同连接刷新失败 | 保留上次列表，明确本次更新失败；不能暗示列表是最新结果 |
| 更换连接、修改配置、重新授权成功 | 清除旧来源列表及恢复确认目标，旧响应不得覆盖新状态 |

- 桌面打开时保留对现有完整云配置的一次自动读取；移动端首次进入使用该云连接的备份、恢复或设置区域时读取。
- 授权、保存并连接成功，以及切换到已有完整配置的服务时，沿用现有只读加载机制。
- 同一次窗口打开期间，页签往返、聚焦和断点变化不反复自动加载。用户仍可手动刷新。
- 从本地恢复切换到云端或导入码时，保留各来源的输入草稿，但最终确认只绑定当前来源及其有效目标；配置版本变化立即使旧云目标失效。
- 备份、恢复和清理共用运行中状态，防止重复执行与冲突操作。运行中可查看其他页签，进度仍然可见；禁止修改正在使用的连接和关键输入。
- 只读列表与写入操作的协调、关闭窗口及恢复后的生命周期继续沿用已验证规则；关闭或重新打开不得额外触发恢复、重试或创建备份。

## 7. 实施方式与顺序

1. 在 `DataManager.vue` 建立统一页签和来源状态，替换桌面长页面与移动端旧任务菜单；控制器保持唯一。
2. 整理备份页，统一位置与内容选择，明确不同目的地的执行结果。
3. 整理恢复页，将列表、所选备份详情、导入码读取和最终恢复动作分开。
4. 将连接表单、帮助、存储统计和维护工具移动到存储设置页。
5. 为三个任务区域提取职责清晰的展示组件；列表与恢复确认可按复用需要拆分。存储访问与快照工具保持原有职责，不引入新的通用表单框架或备份引擎。
6. 同步简体中文、繁体中文和英文文案，更新相关测试及稳定的界面测试标识。

主要改动预计涉及 `packages/ui/src/components/DataManager.vue`、其任务展示子组件、三种语言文件及对应单元和浏览器测试。只有实际接线需要时才调整现有工具层。

工作区当前已有 `ActionButton.vue`、`MainLayout.vue`、`ThemeToggleUI.vue`、`app-layout/AppHeaderActions.vue` 的其他改动，本次实施保留且不混入提交。

## 8. 验证与交付

### 功能与状态回归

- 本地下载备份、云备份与各自恢复完整性通过；工作区草稿、测试结果、收藏与图片不丢失。
- 默认范围、范围依赖、历史 JSON、缺少图片、部分成功等规则不因布局调整改变。
- 导入码读取指定快照后必须再由用户确认；失效码不回退快照，不产生重复恢复。
- Google 模拟授权测试覆盖持久化、授权取消、过期、401、403、网络错误和存储不可用；不冒充真实账号授权验收。
- R2/S3/WebDAV 的既有配置可恢复；保存连接、自动加载和刷新均无上传、建目录或删除请求。
- 刷新失败保留列表；切换来源及重授权后旧响应、旧快照不可进入确认或执行。
- 页签切换、窗口缩放、聚焦、关闭再打开不产生额外恢复或重复自动读取；输入草稿与操作进度符合约定。
- 写入与恢复时的互斥、会话锁和原有恢复完整性测试继续通过。

### 界面验收

- 内置浏览器独立任务标签页验证桌面与移动端；自动化使用现有隔离无界面浏览器。
- 检查 320/390 像素窄屏和常用桌面尺寸、200% 缩放、深浅主题及中英文长文案。
- 验证键盘页签导航、焦点返回、错误与进度提示可感知，主要按钮不会被内容或底部遮挡。
- 使用较多备份记录验证列表可浏览、当前记录可辨认、详情不会全部展开；不为界面统计额外读取备份正文或图片。
- 核心验收任务：完成一次本地备份、一次云备份、一次本地恢复、一次云端恢复、一次导入码恢复，以及一次连接修正后返回原任务。

完成相关单元、集成、类型检查及浏览器验收后，整理独立界面改版提交。本计划不包含推送、新版本发布或正式分支更新。
