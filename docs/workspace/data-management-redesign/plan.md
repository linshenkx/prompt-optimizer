# 数据管理页面改版方案

状态：2026-10-29 整页排版与连接交互调整已在本地完成，按本次请求整理为独立本地提交。视觉自查、子代理独立复核和相关回归均已完成；验证范围见 [验证记录](validation.md)。不含推送或发布。

## 页面结构

保留现有数据管理入口和自适应窗口。桌面和移动端使用同一个页面，依次展示三个区域：

| 区域 | 内容与操作 |
| --- | --- |
| 当前设备数据 | 首屏展示本机应用数据占用估算，可刷新；展开查看应用数据、收藏内容、两类图片占用，以及桌面备份文件和存储目录。备份内容选择在此展开，本地与云端共用。 |
| 本地文件 | 导出备份文件与从文件恢复并列；选文件后先校验、查看内容，再明确确认恢复。 |
| 云端备份 | 连接摘要、创建与刷新、备份记录集中呈现；连接配置原地展开，导入码为辅助入口。 |

- 创建备份后的“查看这份备份”仅定位并突出记录；记录旁的“恢复”才打开确认区。取消恢复保留文件和记录。
- 云端区域直接列出当前平台支持的存储服务；Web 上四种服务均可见，切换无需先展开连接参数。再次点击当前服务不重复请求列表。
- 每条非 Google 记录提供导入码操作，不必先进入恢复确认。导入码读取指定快照后仍须明确确认恢复。
- 本地导出和云端备份的结果各自显示；进度和操作互斥共用同一个控制器。
- 配置表单收起后保留输入。隐藏、显示、缩放和聚焦不会重建控制器或重复加载云列表。
- 记录保留排序、搜索和每页最多 20 条的渲染上限。

## 整页视觉整理

- 用量改为紧凑摘要，明细与共用备份范围保留折叠；与下方操作区区分视觉权重。
- 本地导出和恢复采用统一的图标、标题、辅助说明与控件尺寸；恢复仍支持键盘选择和文件拖入。
- 云服务使用等宽选择入口和明确勾选状态，移动端为两列；导入码位于同一标题行。
- 主区域减少大面积灰底和嵌套卡片；连接表单、列表和恢复确认沿用一致的间距与标题层级。
- 非 Google 表单先填字段，再保存并连接；收起保留输入。暗色按钮文字在该页内修正，不改变全局配色。
- 简体、繁体、英文及 320/390 像素、桌面、暗色、200% 等效布局均纳入检查。

## 占用统计

- 打开窗口时读取一次，另有手动刷新；正在读取时合并重复请求。
- 应用数据复用核心导出边界，纳入图像模型配置和已保存的工作区；收藏文本单独计入。图片使用已有统计接口，不加载图片正文。
- 数值是应用数据估算，不是云服务配额、磁盘剩余空间或浏览器存储配额。
- 部分读取失败时保留已知数值并提示不完整；全部读取失败显示不可用，不能伪装成零占用。
- 本次不新增云端配额查询、后台轮询或实时统计服务。

## 继续保持的行为

- 连接入口统一为「连接配置」，同一按钮展开或收起完整表单；移除二次展开、重复标题与通用平台推荐说明。未配置的 R2/S3/WebDAV 自动展开，已保存完整配置时默认展示列表；Google 首次仍直接授权。显式连接或重新授权后，本次列表读取成功才收起配置，失败保留输入和提示；过时请求不能收起新连接的表单。

- Google 凭据独立本地持久化，不自动续期、清理或弹授权；其他服务保持配置格式。令牌不进入普通备份。
- 连接和列表读取只读，写权限在实际备份时验证。列表失败与成功为空分开；旧连接的响应不能覆盖新连接。
- 本地文件、云端记录和导入码的目标独立。更换文件或连接后旧目标失效，异步旧文件读取不能覆盖新文件。
- 导出前保存工作区，恢复使用现有完整性校验、会话锁和范围依赖。ZIP、历史 JSON、图片缺失和部分成功提示保持兼容。
- 不修改备份格式、远程目录、已有数据、导入码格式、版本号；不增加后端、自动同步或数据迁移。
- 简体中文、繁体中文、英文同步维护；复用现有主题、组件和响应式布局。

## 验证与交付

- 复用组件、存储与资源包专项测试，覆盖统计错误、明确恢复动作、草稿保留、请求互斥与指定快照。
- 无界面浏览器运行本地 ZIP 和云端往返恢复、图片解码、导入码跨上下文恢复、模拟 Google 授权、只读 WebDAV。
- 检查 320/390 像素窄屏、桌面、深浅主题、键盘焦点和 200% 等效布局。
- 界面验收优先内置浏览器独立标签页；连接不可用时记录限制并使用隔离无界面截图，不打开用户浏览器。
- 本轮按用户要求整理本地提交；不推送、不发布。保留工作区其他任务的改动。
