### 组内配置入口修复

每组右侧原先的“配置”是静态说明，容易误认为可点击入口。现改为真正的按钮，通过应用层统一接口打开所点配置的现有编辑弹窗；底部“管理配置”仍打开完整列表。配置入口不会触发模型选择或保存，模型编辑沿用现有管理流程。

### 统一剩余模型入口

所有模型列表复用 ModelSelector.vue 的展示、搜索、分组、每组最多三项、更多、键盘操作与视觉视口避让。TextModelSelector、ImageModelSelector 和 ModelIdSelector 只适配数据与选择含义，不再各自实现菜单。

| 入口 | 选择与保存范围 |
| --- | --- |
| 文本工作区 / 文本测试列 | 继续使用局部配置与模型引用，不修改共享连接配置。 |
| 图像生成测试列 | 继续选择已保存图像配置，保留传入的能力筛选，不改变其他列。 |
| 评估 / 图像识别功能设置 | 保存为各自全局功能偏好；支持所选配置内其他模型，并保留评估清除后跟随默认的规则。 |
| 文本 / 图像配置编辑 | 选择已有或自定义模型 ID、清除和刷新仍更新原表单草稿；保存才修改共享配置，取消保留旧值。 |

图像工作区原来单独的快捷标签会直接修改共享配置。该操作现在统一从组内“配置”进入原编辑弹窗并保存；模型修改功能保留，同时移除工作区重复标签，避免把共享编辑误认为列内选择。兼容导出的两种 QuickSwitch 内部也复用 ModelIdSelector，并明确即时修改共享配置的范围。

窄于 190px 的控件优先展示模型名，完整配置与模型名保留在 title 和展开列表中。菜单每次打开回到当前配置，从搜索或更多返回时重置滚动位置。菜单复用已有 useSelectMenuViewport，避免软键盘遮挡。
