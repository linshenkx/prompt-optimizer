# Prompt Optimizer MCP

在 Codex、Claude Desktop 等 AI 助手里使用你已有的提示词优化器。你可以贴入提示词，也可以从收藏中选一条，用自己配置的模型优化、对照测试并评估结果。满意后，可以把优化结果存入历史记录，或把定稿加入收藏。

> 帮我优化这句提示词：“把工作记录写成周报。”用同一个模型分别测试原版和新版。工作记录是“周一修复登录超时，周三上线，周五收到两条用户反馈”。把两份周报放在一起给我看。

## 接入 AI 助手

从 `0.2.0-beta.4` 起，使用 Node.js 24、25 或 26，在 MCP 客户端填写以下 `stdio` 启动命令。

```sh
npx -y @prompt-optimizer/mcp-server@beta
```

如果客户端分开填写命令和参数，命令填 `npx`（Windows 可填 `npx.cmd`），两个参数分别填 `-y` 和 `@prompt-optimizer/mcp-server@beta`。默认使用本机桌面资料。

## 选择要使用的资料

- **桌面版（默认）** 直接使用本机已有的桌面资料。关闭桌面应用也能优化、测试和保存。操作桌面图片库或导入导出完整 ZIP 备份时，需要打开 Windows 桌面应用。
- **网页版（含自部署站点）** 把平时使用的完整网址告诉助手，或用启动参数 `--product-url=<网址>` 设为默认。用平时访问该站点的浏览器和个人资料打开助手给出的链接，点击「允许连接」，操作期间保持该标签页开启。同一网址在 Chrome、Edge 或不同个人资料中可以有不同的数据。
- **独立资料目录** 用启动参数 `--desktop-profile=<绝对目录>` 指向一份已初始化的桌面资料，例如已有资料的副本。即使这台机器没有安装桌面版，也能读写其中的模型配置、收藏和历史，重启后继续使用。直接指定空目录会提示资料尚未就绪。
